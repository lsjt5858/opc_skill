# AI 电影制片导演 交付物的分批输出

当请求的交付物较大，单次回复可能丢失镜头级细节、跳过资产或压缩 QC 时，使用分批输出。

## 何时分批

根据以下因素共同判断是否需要分批，不设固定镜头数或资产数阈值：

- **镜头数量**：当前输出能否逐镜完整展开，而不压缩或遗漏栏目；
- **资产依赖复杂度**：跨镜角色、状态、道具、环境和文字策略是否需要分组才能准确追踪；
- **动作与声音密度**：时间段、动作层和声音层是否能在一批内保持清晰；
- **完整 QC**：单次输出能否为每个镜头保留完整 QC 和包级核验。

只要单次输出能完整保留资产依赖、镜头细节和 QC，就不分批；小任务不分批。

## 分批计划格式

写大型输出前，先简短说明：

```text
我会分 {batch_count} 批输出，避免镜头细节被压缩：
- 第 {batch_index} 批覆盖范围：{具体资产、镜头 ID 或后期/QC 交付物}
- 分批依据：{镜头数量 / 资产依赖复杂度 / 动作与声音密度 / 完整 QC}
- 下一批覆盖范围：{具体范围；最后一批写“无”}
```

批次数量与覆盖范围按项目实际复杂度确定，不套用默认镜头分组。

## 分批内容规则

- 第 1 批必须锁定 Production Spec、镜头卡中的每镜实际生成模式、`Dependency asset IDs`、`Input handles`、时间线和文字政策；后续批次不得静默修改这些已锁定内容，发现冲突时应显式停下并回报。Production Spec 只记录平台能力、允许的生成模式和默认生成模式策略，不记录每镜实际模式。
- 每一批开头声明本批覆盖范围，包括具体资产、镜头 ID 或后期/QC 交付物。
- 每批可重复镜头卡的模式无关 `Dependency asset IDs`。I2V/参考驱动批次的 `Input handles` 必须与这些 ID 逐项一致映射，只重复实际存在、平台支持的 `{input_handle}`；`{input_handle}` 可映射为 token、附件、URL 或 API 字段。正文锚定与 QC 逐项与 `【本镜输入】` 一致。若包含结束帧，该资产必须从对应镜头卡已锁定的 `Canonical tail state / 权威尾帧定义` 派生，并与全部结构化字段一致；无法保证时只允许起始帧输入或阻塞修正。纯 T2V 批次保留 `Dependency asset IDs`，但 `Input handles` 与 `【本镜输入】` 必须为 `无/不适用`，不得传入来源帧或结束帧资产。
- 所有批次保持镜头 ID 稳定。
- 已锁定且需保持连续性的固定饰品可保留；禁止随机饰品和未锁定职业道具。
- 每批结尾写清楚下一批覆盖范围。
- 如果可以自动继续，就不要等待用户确认。
- 如果受回复长度或轮次中断限制无法继续，告诉用户下一步要请求的精确批次。

每个镜头的生成模式写法互斥，不得同时输出：

- **I2V/参考驱动**：镜头卡是实际模式真源；仅在 Production Spec 记录的平台能力允许时使用，且 `Dependency asset IDs` 与 `Input handles` 逐项一致映射；结束帧输入必须从镜头卡 canonical tail state 派生，否则只传起始帧或阻塞修正。
- **纯 T2V**：镜头卡保留 `Dependency asset IDs`，清空 `Input handles`，不传入任何来源帧或结束帧资产；以依赖资产的完整文本连续性 DNA 和开始状态承载连续性，十栏目 `【尾帧】` 忠实映射镜头卡 canonical tail state。

若原定 I2V/参考驱动镜头的平台不支持参考输入，不得在当前批次静默省略输入继续生成。必须先更新镜头卡，将该镜 `Generation mode` 显式改为纯 T2V，保留 `Dependency asset IDs`、清空 `Input handles` 并重写对应提示词，再重跑所有受生成模式、拆镜、资产依赖、storyboard/keyframe 策略影响的 Gate；只有全局默认生成模式策略也改变时才同步 Production Spec。任一受影响 Gate 未通过则阻塞。否则更换为支持参考输入的平台。

## 每个镜头的最低细节

不要把单个镜头压缩到低于这些字段：

- 生成模式、依赖与输入：下游只读取镜头卡 `Generation mode`；两种模式都保留 `Dependency asset IDs`；I2V/参考驱动的 `Input handles` 与依赖 ID 逐项映射，正文锚定与 QC 均与 `【本镜输入】` 一致；纯 T2V 清空 `Input handles`，不传来源帧或结束帧资产，并完整写明文本连续性 DNA 和开始状态；两种模式的十栏目 `【尾帧】` 都忠实映射镜头卡 canonical tail state；
- 风格锁定；
- 声音规则；
- 当前状态下的资产锚点；
- 镜头组织；
- 机位与构图；
- 动作节奏；
- 尾帧；
- 铁律与负面约束；
- 后期文字/声音说明；
- QC。
