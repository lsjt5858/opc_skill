# 人工智能电影制作流程

用于端到端制片计划、场景/镜头拆解、animatic、生成顺序和剪辑交付。

## 目录

1. 制片简报

## 1. 制片简报

- **已锁定**：有明确来源，后续阶段必须遵守；变更时重新检查受影响资产。
- **推断**：为推进工作采用的可逆选择，必须写明依据并允许用户覆盖。
- **待确认**：会影响当前或下一阶段的决策，未确认时不得越过对应关口。
- **可延后**：当前阶段不依赖，可在其首次成为依赖前补齐。

参考图可以使用便于审阅的临时网格。所有 storyboard panel、keyframe 和视频镜头必须使用 Production Spec 锁定的最终交付比例。

## 2. 场景与镜头规划

先建立场景列表，再生成最终提示词：

| Scene ID | 故事作用 | 地点/时间 | 角色 | 关键道具 | 声音 | 预估时长 |
|---|---|---|---|---|---|---|

每个剪辑单位创建一张镜头卡：

```text
Shot ID: SC01-SH01
Duration:
Story purpose:
Framing/lens feel:
Start state:
Subject motion:
Camera motion:
Environment motion:
End state:
Dialogue/voice-over:
Sound cue:
Reference assets:
Continuity notes:
Transition in/out:
```

当一个镜头包含多个独立动作、地点跳转、身份敏感变化，或视频模型难以保持的摄影机运动时，拆分镜头。

## 3. 临时声音与 Animatic

Animatic 只适用于叙事、对白容量、跨镜覆盖或节奏判断会影响下游生产的项目。单资产、单镜静帧、非叙事或无节奏依赖的任务应将 Animatic 标记为 `不适用`，并记录判断依据，不为通过流程而制作。

适用时：

1. 录制临时对白/旁白，或使用临时 TTS。
2. 把黑场、草图或低成本 storyboard panel 对到声音上。
3. 添加控制节奏的必要声音提示。
4. 验证开场钩子、揭示停顿、情绪峰值和结尾停留。
5. 在生成昂贵最终素材前锁定大致镜头时长。

Animatic 用于验证叙事和覆盖，不要求最终脸部或材质。

## 4. 资产依赖分级

### 资产 A 级 — 可复用 bible 资产

- 风格与色卡规则；
- 主角中性身份/转面图；
- 反复出现的核心道具；
- 重复空场景与空间布局。

### 资产 B 级 — 表演与状态资产

- 服装和年龄变体；
- 表情图；
- 困难或重复姿势图；
- 伤痕、天气、污渍、损坏或变身状态；
- 环境光线/天气变体。

### 资产 C 级 — 镜头资产

- Storyboard panel；
- 镜头专属起止 keyframe；
- 插入镜头和微距细节；
- Image-to-video 提示词；
- 关键文字合成。

按复用和依赖关系生成，不要只按剧本出现顺序生成。

## 5. 角色覆盖

### 主角或高复用角色

分开创建：

1. 中性身份/转面图；
2. 面部 close-up 和识别细节；
3. 每套重复服装/状态；
4. 表情图；
5. 只为困难或重复动作创建姿势图；
6. 年龄变体，并写明共享面部锚点。

### 反复出现的配角

创建正面、3/4、面部 close-up、主服装，以及必要的表情/动作图。

### 一次性角色或背景人物

使用紧凑 casting card。除非后续镜头需要，不要做完整转面图。

身份图必须使用中性姿势、受控光线和纯背景。不要用坐着哭泣、打斗或其他剧情姿势来替代缺失的身份视图。

## 6. 道具与环境覆盖

### 反复出现的道具

写清尺寸、归属者、材质、拿取逻辑、状态变体和精确标记/损坏位置。先展示正交/参考视图，再做电影感插入镜头。

### 环境

先创建空场景：

- 主视角大远景；
- 空间布局或俯视关系；
- 主要拍摄方向；
- 反方向；
- 关键区域细节；
- 故事变化时的光线/天气变体。

追踪入口、出口、窗、门、家具、危险点和核心道具位置，让反打镜头保持连贯。

## 7. Keyframe 与视频

从明确参考组合最终 keyframe：

```text
角色身份 + 服装/状态 + 表情/动作
+ 道具状态
+ 空环境/摄影方向
+ 镜头卡构图和光线
= 镜头 keyframe
```

对状态变化动作、match cut、强 blocking 变化或身份敏感的情绪转折，使用起始帧和结束帧。

视频提示词必须始终分开描述：

- 来源/起始帧；
- 主体运动；
- 摄影机运动；
- 环境运动；
- 时间节拍；
- 结束状态；
- 负面运动约束。

片段时长由 animatic、动作容量和所选模型能力共同决定。拆分复杂动作，不要让一个片段承担多个独立节拍。

## 8. 剪辑与阶段关口

每个关口只在进入条件可观察地满足后开始，并以产物检查结果作为退出依据。任一关口未通过时，固定返回：

```text
阻塞项：{缺失、冲突或不合格的具体信息/产物}
下游影响：{不能可靠开展或需要返工的阶段与资产}
最小解决方案：{解除阻塞所需的最小决定、补充或返修}
仍可继续完成的部分：{不依赖阻塞项的工作；没有则写“无”}
```

先按项目实际依赖标记各 Gate 为 `适用` 或 `不适用`，并记录依据。完整叙事成片通常使用 Gate 0-5；单资产、单镜或非叙事任务只经过其交付物实际依赖的 Gate。进入下游 Gate 时，只要求前一个适用 Gate 已通过；被明确标记为 `不适用` 的 Gate 不构成阻塞。

### Gate 0 — Production Spec and continuity

- **进入条件**：已收到用户指令、源材料、已检查素材或平台约束中的至少一种，并建立七组 Production Spec。
- **退出条件**：所有影响下一个适用阶段的值均为已锁定或有依据的推断；待确认项已被阻塞或明确可延后；只对当前交付物涉及的时间线、年龄、身份、地点、道具状态、关键文字和可生产性完成审计，整体准入结论为通过或有条件通过。

### Gate 1 — Scene list, shot cards, animatic

- **进入条件**：Gate 0 退出条件已满足；项目存在场景/镜头拆解、叙事、对白容量、跨镜覆盖或节奏验证依赖。
- **退出条件**：场景列表覆盖全部适用故事节拍；每个剪辑单位都有镜头卡及开始/结束状态；需要 Animatic 时，其无最终画面也能读懂故事，且时长、台词容量、动作覆盖、声音提示和转场接口均经检查；不需要时明确记录 `Animatic：不适用` 及依据。没有上述依赖的任务可将 Gate 1 整体标记为 `不适用`。

### Gate 2 — reusable assets

- **进入条件**：Gate 1 已通过或明确标记为 `不适用`；当前交付物需要可复用资产，并已有资产清单和依赖顺序。
- **退出条件**：当前交付物所需的角色身份/转面、服装与状态、核心道具、空环境或空间布局资产已生成并通过一致性检查；每项资产有稳定标识、来源和可引用版本。不需要可复用资产时，Gate 2 可标记为 `不适用`。

### Gate 3 — storyboard/keyframes

- **进入条件**：前一个适用 Gate 已通过，跳过的 Gate 已明确标记为 `不适用`；当前交付物需要 storyboard 或 keyframe，且其所依赖的身份、状态、道具和环境参考均可引用。
- **退出条件**：storyboard 或 keyframe 覆盖当前交付物所需镜头并符合交付比例；存在相邻镜头时，其站位、视线、屏幕方向、手/道具状态、光线、构图变化及开始/结束状态可连续；依赖未定义空间关系的最终 keyframe 不得通过。不需要 storyboard 或 keyframe 时，Gate 3 可标记为 `不适用`。

### Gate 4 — video generation

- **进入条件**：前一个适用 Gate 已通过，跳过的 Gate 已明确标记为 `不适用`；当前交付物需要视频生成，且每镜已锁定适用的来源帧、运动描述、时间节拍、结束状态和负面运动约束。
- **退出条件**：所有计划片段均已生成并逐镜质检；运动和物理可信，身份与状态不漂移，无非预期文字或伪影，需要衔接时结束状态可接入下一镜；失败片段已有返修或替代决定。不需要视频生成时，Gate 4 可标记为 `不适用`。

### Gate 5 — edit/sound/text/delivery

- **进入条件**：前一个适用 Gate 已通过，跳过的 Gate 已明确标记为 `不适用`；当前交付物需要剪辑、声音、文字或最终文件交付，且所需素材可用。
- **退出条件**：仅检查当前交付物适用的剪辑、声音、文字和交付项；使用 Animatic 时画面剪辑与其意图一致，Animatic 不适用时不作此要求；最终文件符合 Production Spec 中已锁定的交付约束，并完成适用的可播放性和版本核验。

制片计划类请求结尾给出 3-8 个按依赖顺序排列的立即行动。用户不应需要先阅读完整提示词包才能开始。
