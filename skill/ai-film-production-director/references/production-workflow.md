# 人工智能电影制作流程

用于端到端制片计划、场景/镜头拆解、animatic、生成顺序和剪辑交付。

## 目录

1. 制片简报
2. 场景与镜头规划
3. 临时声音与 animatic
4. 资产依赖分级
5. 角色覆盖
6. 道具与环境覆盖
7. Keyframe 与视频
8. 剪辑与阶段关口

## 1. 制片简报

先建立 Production Spec，作为所有阶段共享的制片真源：

| 变量组 | 必填变量 | 值 | 值状态 | 来源 |
|---|---|---|---|---|
| 故事变量 | 主题、受众、情节节拍、角色关系、时间线、地点、关键道具与文字 |  |  |  |
| 交付变量 | 发布平台、画幅、总时长、分辨率、帧率、语言、字幕、文件格式与版本 |  |  |  |
| 视觉变量 | 写实/风格化程度、时代、色彩、光线、摄影语言、构图与连续性锚点 |  |  |  |
| 表演变量 | 角色年龄/身份、服装状态、动作、情绪、对白、旁白与口型需求 |  |  |  |
| 声音变量 | 对白、旁白、环境声、动作声、特殊音效、音乐策略、响度与混音要求 |  |  |  |
| 生成变量 | 工具/模型、输入类型、参考素材限制、片段能力、控制方式、预算与重试策略 |  |  |  |
| 后期变量 | 剪辑节奏、转场、调色、合成、关键文字、字幕、声音精修、质检与交付规范 |  |  |  |

每个值必须标记为 `已锁定 | 推断 | 待确认 | 可延后`，并记录一个或多个来源：`用户指令 / 源材料 / 已检查素材 / 平台约束`。

- **已锁定**：有明确来源，后续阶段必须遵守；变更时重新检查受影响资产。
- **推断**：为推进工作采用的可逆选择，必须写明依据并允许用户覆盖。
- **待确认**：会影响当前或下一阶段的决策，未确认时不得越过对应关口。
- **可延后**：当前阶段不依赖，可在其首次成为依赖前补齐。

参考图可以使用便于审阅的临时网格。所有 storyboard panel、keyframe 和视频镜头必须使用 Production Spec 锁定的最终交付比例。

## 2. 场景与镜头规划

先建立场景列表，再生成最终提示词：

| Scene ID | 故事作用 | 地点/时间 | 角色 | 关键道具 | 声音 | 预估时长 |
|---|---|---|---|---|---|---|

每个剪辑单位创建一张镜头卡：

```text
Shot ID: SC01-SH01
Duration:
Story purpose:
Framing/lens feel:
Start state:
Subject motion:
Camera motion:
Environment motion:
End state:
Dialogue/voice-over:
Sound cue:
Reference assets:
Continuity notes:
Transition in/out:
```

当一个镜头包含多个独立动作、地点跳转、身份敏感变化，或视频模型难以保持的摄影机运动时，拆分镜头。

## 3. 临时声音与 Animatic

叙事类项目建议：

1. 录制临时对白/旁白，或使用临时 TTS。
2. 把黑场、草图或低成本 storyboard panel 对到声音上。
3. 添加控制节奏的必要声音提示。
4. 验证开场钩子、揭示停顿、情绪峰值和结尾停留。
5. 在生成昂贵最终素材前锁定大致镜头时长。

Animatic 用于验证叙事和覆盖，不要求最终脸部或材质。

## 4. 资产依赖分级

### 资产 A 级 — 可复用 bible 资产

- 风格与色卡规则；
- 主角中性身份/转面图；
- 反复出现的核心道具；
- 重复空场景与空间布局。

### 资产 B 级 — 表演与状态资产

- 服装和年龄变体；
- 表情图；
- 困难或重复姿势图；
- 伤痕、天气、污渍、损坏或变身状态；
- 环境光线/天气变体。

### 资产 C 级 — 镜头资产

- Storyboard panel；
- 镜头专属起止 keyframe；
- 插入镜头和微距细节；
- Image-to-video 提示词；
- 关键文字合成。

按复用和依赖关系生成，不要只按剧本出现顺序生成。

## 5. 角色覆盖

### 主角或高复用角色

分开创建：

1. 中性身份/转面图；
2. 面部 close-up 和识别细节；
3. 每套重复服装/状态；
4. 表情图；
5. 只为困难或重复动作创建姿势图；
6. 年龄变体，并写明共享面部锚点。

### 反复出现的配角

创建正面、3/4、面部 close-up、主服装，以及必要的表情/动作图。

### 一次性角色或背景人物

使用紧凑 casting card。除非后续镜头需要，不要做完整转面图。

身份图必须使用中性姿势、受控光线和纯背景。不要用坐着哭泣、打斗或其他剧情姿势来替代缺失的身份视图。

## 6. 道具与环境覆盖

### 反复出现的道具

写清尺寸、归属者、材质、拿取逻辑、状态变体和精确标记/损坏位置。先展示正交/参考视图，再做电影感插入镜头。

### 环境

先创建空场景：

- 主视角大远景；
- 空间布局或俯视关系；
- 主要拍摄方向；
- 反方向；
- 关键区域细节；
- 故事变化时的光线/天气变体。

追踪入口、出口、窗、门、家具、危险点和核心道具位置，让反打镜头保持连贯。

## 7. Keyframe 与视频

从明确参考组合最终 keyframe：

```text
角色身份 + 服装/状态 + 表情/动作
+ 道具状态
+ 空环境/摄影方向
+ 镜头卡构图和光线
= 镜头 keyframe
```

对状态变化动作、match cut、强 blocking 变化或身份敏感的情绪转折，使用起始帧和结束帧。

视频提示词必须始终分开描述：

- 来源/起始帧；
- 主体运动；
- 摄影机运动；
- 环境运动；
- 时间节拍；
- 结束状态；
- 负面运动约束。

片段时长由 animatic、动作容量和所选模型能力共同决定。拆分复杂动作，不要让一个片段承担多个独立节拍。

## 8. 剪辑与阶段关口

每个关口只在进入条件可观察地满足后开始，并以产物检查结果作为退出依据。任一关口未通过时，固定返回：

```text
阻塞项：{缺失、冲突或不合格的具体信息/产物}
下游影响：{不能可靠开展或需要返工的阶段与资产}
最小解决方案：{解除阻塞所需的最小决定、补充或返修}
仍可继续完成的部分：{不依赖阻塞项的工作；没有则写“无”}
```

### Gate 0 — Production Spec and continuity

- **进入条件**：已收到用户指令、源材料、已检查素材或平台约束中的至少一种，并建立七组 Production Spec。
- **退出条件**：所有影响下一阶段的值均为已锁定或有依据的推断；待确认项已被阻塞或明确可延后；时间线、年龄、身份、地点、道具状态、关键文字和剧本可生产性完成审计，结论为通过或有条件通过。

### Gate 1 — Scene list, shot cards, animatic

- **进入条件**：Gate 0 退出条件已满足，故事节拍、交付时长和声音需求可用于拆解。
- **退出条件**：场景列表覆盖全部故事节拍；每个剪辑单位都有镜头卡及开始/结束状态；animatic 可在无最终画面时读懂故事，且其时长、台词容量、动作覆盖、声音提示和转场接口均经检查。

### Gate 2 — reusable assets

- **进入条件**：Gate 1 退出条件已满足，镜头卡已给出可复用资产清单和依赖顺序。
- **退出条件**：所需角色身份/转面、服装与状态、核心道具、空环境及空间布局资产已生成并通过一致性检查；每项资产有稳定标识、来源和可引用版本。

### Gate 3 — storyboard/keyframes

- **进入条件**：Gate 2 退出条件已满足；镜头所依赖的身份、状态、道具和环境参考均可引用。
- **退出条件**：storyboard 覆盖全部镜头；最终 keyframe 符合交付比例；相邻镜头的站位、视线、屏幕方向、手/道具状态、光线、构图变化及开始/结束状态可连续；依赖未定义空间关系的最终 keyframe 不得通过。

### Gate 4 — video generation

- **进入条件**：Gate 3 退出条件已满足；每镜已锁定来源帧、运动描述、时间节拍、结束状态和负面运动约束。
- **退出条件**：所有计划片段均已生成并逐镜质检；运动和物理可信，身份与状态不漂移，无非预期文字或伪影，结束状态可接入下一镜；失败片段已有返修或替代决定。

### Gate 5 — edit/sound/text/delivery

- **进入条件**：Gate 4 退出条件已满足，全部通过或获准替代的视频片段、声音素材和后期文字稿可用。
- **退出条件**：画面剪辑与 animatic 意图一致；对白节奏、room tone、环境声、动作声、特殊音效、音乐、响度、颜色连续性、字幕和关键文字均已检查；最终文件符合 Production Spec 的平台与交付约束，并完成可播放性和版本核验。

制片计划类请求结尾给出 3-8 个按依赖顺序排列的立即行动。用户不应需要先阅读完整提示词包才能开始。
