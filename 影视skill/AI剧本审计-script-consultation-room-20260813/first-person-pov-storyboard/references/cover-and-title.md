## 封面设计法则

### 双格封面

头部创作者的标志性封面格式：

```
┌──────────┬──────────┐
│          │          │
│  左格    │  右格    │
│ 情绪/氛围 │ 关键道具  │
│          │ 或人物    │
│          │          │
├──────────┴──────────┤
│     《两字标题》      │
└─────────────────────┘
```

- **左格**：氛围/情绪画面，用色彩和光线传达情绪基调（如冷色背影、暖色家庭）；
- **右格**：关键道具、人物特写或核心画面（如寻人启事、手部、泪水）；
- **两格之间**：可以是自然分割（环境色差），也可以用极细白线分隔；
- **底部或居中**：两字标题加书名号，白色或金色大字。

### 封面选图原则

| 原则 | 说明 |
|---|---|
| 情绪优先 | 左格必须让人 0.3 秒内感受到情绪（冷=孤独，暖=温暖） |
| 道具为锚 | 右格放贯穿道具或核心画面，建立"这个视频关于什么" |
| 色彩对比 | 左右两格色温/饱和度形成对比（暖vs冷），制造视觉张力 |
| 人物不完整 | 优先用侧脸、背影、手部，不用完整正脸（保持悬念感） |
| 标题不抢戏 | 标题字号适中，不遮住画面主体情绪 |

### 封面提示词写法

**左格（情绪氛围）**：

```text
[竖版画面]，[场景/人物背影或侧脸]，[色温与情绪]，[光线质感]，[模糊程度]，电影级画面，高情绪密度，留出底部三分之一用于标题，9:16
```

**右格（道具/特写）**：

```text
[竖版画面]，[道具/手部/人物局部特写]，[清晰可见的细节]，[与左格形成色温对比的光线]，[景深]，电影级画面，9:16
```

**整版合成说明**（给后期或 AI 合成工具）：

```text
将左格[描述]与右格[描述]左右拼接为一张 9:16 竖图，中间用极细白线分隔，底部居中叠加白色大字"《[两字标题]》"，字体为[字体选择]，两格色温形成[暖/冷]对比。
```

## 标题设计法则

### 两字原则

- 全部标题为**两个汉字 + 书名号**：《守护》《归栖》《微光》《本真》《种子》
- 选词为**抽象情感词**，不是情节词（不用"寻人""被骗""重逢"）；
- 词汇来源：
  - 情感状态：守望、等待、归途、余光
  - 自然意象：微光、星辰、暮色、晨曦
  - 人文概念：本真、守护、种子、薪火
  - 动作隐喻：归栖、远行、回响
- 同账号标题风格统一，建立品牌识别。

### 标题与内容的映射

标题不是内容摘要，而是情感核心。观众看完后回想"原来这就是守护/微光/归栖"，形成闭环。

| 标题 | 适用内容 | 情感核心 |
|---|---|---|
| 守护 | 长期坚持、保护某人 | 不放弃 |
| 归栖 | 重逢、回家、找到 | 归属 |
| 微光 | 绝望中的希望 | 仍有光 |
| 本真 | 回归初心、本质 | 纯粹 |
| 种子 | 传承、开始、希望 | 生生不息 |
| 余光 | 回望、遗憾、记忆 | 挥之不去 |
| 归途 | 寻找、旅途、方向 | 在路上 |
| 暮色 | 衰老、消逝、告别 | 时间 |

## 账号视觉统一

### 封面统一策略

- 全账号封面使用相同的：双格布局、标题字体、标题位置、分隔方式；
- 每条视频封面只在"内容"上不同，"框架"完全一致；
- 这让观众在信息流中一眼认出"这是这个账号的视频"。

### 色彩统一策略

- 全账号主色调一致（如偏暖黄/偏冷青）；
- 每条视频在这个主色调上做微调，而非完全换色；
- 封面左格的色温是账号品牌色。
