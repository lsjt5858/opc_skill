## 一致性优先级

资源有限时按此顺序保证，不要平均用力：

1. **核心人物身份**：观众一旦觉得换人，故事失效；
2. **贯穿道具版式**：锚点变了，时间线断裂；
3. **叙事者手部与袖口**：第一人称的身份凭证；
4. **场景空间格局**：同一地点不能忽然改变结构；
5. **光线与色调曲线**：影响情绪连贯；
6. **次要路人与背景细节**：可放宽。

## 身份锁定操作法

**步骤**：

1. 先生成"母版参考图"：中性光、正面、简洁背景、表情中性；
2. 从母版派生多视图（侧面、半身、全身、情绪版），每次都引用母版；
3. 提炼 5–8 条文字化"身份锁"，写进每个镜头提示词；
4. 所有剧情镜头以母版作为参考图输入，而非纯文字生成；
5. 出现漂移时，回到母版重做，不要在漂移图上继续派生。

**身份锁写法示例**：

```text
同一名 30 岁中国女性：圆脸、单眼皮、鼻梁略低、左眉尾有小疤、
中长直发自然分缝、耳后碎发、身形偏瘦、深灰旧夹克、无妆感
```

**要点**：

- 身份锁只写不变的骨相与标识，不写情绪和角度；
- 避免使用"漂亮、气质好"等无法约束的形容；
- 儿童角色尤其容易漂移，务必固定五官比例与发型细节；
- 同一角色跨年龄时，保留眼型、眉形、鼻型、脸型四项。

## 手部稳定策略

手是第一人称的主角，也是最易崩坏处。

**降低难度**：

- 优先单手入画，双手仅在必要时（持纸、捧物、拥抱）；
- 让手与物体有明确接触关系，避免悬空；
- 手部处于画面下缘或侧缘，减少完整手掌暴露；
- 避免张开五指正对镜头；
- 复杂操作拆成"接近—接触—完成"三镜。

**提示词写法**：明确写"右手"或"左手"、指节状态、与物体的包握方式，例如"右手四指从下方托住纸张，拇指压在纸面左上角"。

**修复顺序**：重生成 → 换手部姿态设计 → 局部重绘手部 → 改为手部出画（用袖口或前臂替代）。

## 文字与界面资产工艺

不要让生成模型承担关键文字。

**流程**：

1. 用设计工具或代码生成文字资产（海报、短信、证件、界面），导出透明底 PNG；
2. 生成镜头时，画面中对应位置写"留出空白纸面/熄屏状态"；
3. 后期用合成软件贴入并匹配透视、光影、颗粒；
4. 需要纸张弯曲时，在合成阶段做置换变形。

**若必须由模型生成文字**：只允许短词（2–4 字）、大字号、正面平视、高对比，且必须逐帧检查。

**合规**：所有号码、姓名、地址、证件号使用虚构信息；不使用真实机构标识与真人肖像。

## 跨年龄与跨年代一致性

| 维度 | 保持不变 | 允许变化 |
|---|---|---|
| 面部 | 眼型、眉形、鼻型、脸型轮廓 | 皱纹、肤色、松弛度、发色 |
| 手部 | 骨架比例、惯用手 | 皮肤纹理、斑点、干燥度 |
| 道具 | 结构、版式、尺寸 | 磨损、污渍、折痕、泛黄 |
| 场景 | 空间格局、承重结构 | 家具、招牌、电器、车辆 |
| 服装 | 标志性单品 | 款式年代、新旧程度 |

年代信号优先用环境（手机形态、招牌样式、车型）而非字幕。

## 模型能力适配与降级

不同生成能力对复杂度容忍度不同。判断顺序：

1. **能否稳定生成手部** → 不稳则减少手部暴露，改用袖口、前臂、影子；
2. **能否接受参考图** → 不能则强化文字身份锁，并接受更高废片率；
3. **能否控制首尾帧** → 不能则把动作拆得更短更单一；
4. **能否生成中文** → 默认视为不能，全部走后期贴图；
5. **单镜可用时长** → 超出上限一律拆镜。

**降级策略**：

- 复杂交互 → 拆成多个单动作镜头；
- 大幅位移 → 改为固定站位加视线转移；
- 多人同框表演 → 减少同框人数，用画外声补足；
- 长镜头 → 拆成同构图连续短镜，剪辑上无缝拼接。

不要为了炫技保留无法稳定生成的设计。

## 首尾帧与拆镜策略

**适合用首尾帧控制**：视线从 A 转到 B、门从关到开、物体从远到近、光线由暗到亮。

**必须拆镜的情况**：一镜内出现两次以上状态变化；同时有大位移和精细手部动作；多人依次做出反应；画面主体完全更换。

**拆镜方法**：按"接近—接触—反馈"或"刺激—转视—确认"切分，保证每镜只有一个动作与一个焦点变化。

## 光线与调色连续性

- 为每个叙事阶段定义色温、对比度、饱和度三项数值化目标；
- 同一场景内保持光源方向一致，写明主光来自哪一侧；
- 情绪转折用光线变化承载，而非突然换调色风格；
- 真实素材与生成素材混剪时，统一加颗粒与轻微暗角以拉平质感差异；
- 避免全片高光溢出与过度锐化，保留暗部细节。

## 生成排错处方

| 症状 | 根因 | 处方 | 优先级 |
|---|---|---|---|
| 画面变成第三人称 | 提示词缺身体证据，或含"展示某人"类表述 | 补双手/前臂/视线目标，删除展示性措辞，加视角负面词 | 最高 |
| 人物前后不像 | 逐镜独立生成，无母版 | 建立母版参考图并全镜引用，重做漂移镜 | 最高 |
| 手指畸形或多手 | 手部暴露过多、姿态复杂 | 简化姿态、单手入画、局部重绘或改出画 | 最高 |
| 中文乱码 | 让模型直接写字 | 改为后期贴图资产 | 最高 |
| 道具版式跳变 | 未固定版式描述 | 制作道具母版，写明尺寸颜色结构 | 高 |
| 画面像广告 | 灯光过精致、构图过干净、皮肤过光滑 | 加环境杂物、生活痕迹、真实皮肤纹理、降低饱和 | 高 |
| 镜头运动不像人 | 使用轨道、环绕类描述 | 改写为呼吸、步幅、转头等人体动作 | 高 |
| 动作没发生 | 动态提示词无明确起止 | 补起始与结束状态，缩短动作幅度 | 高 |
| 情绪不到位 | 只靠表演，缺代价与时间 | 补代价镜头、重复动作、环境反应 | 中 |
| 剪辑接不上 | 相邻镜头手与视线状态冲突 | 对齐 end_state 与 start_state，必要时加过渡镜 | 中 |
| 时长与目标不符 | 未逐镜核算 | 运行 `scripts/check_storyboard.py` 实数核对 | 中 |
| 背景人物抢戏 | 背景过于清晰或动作过大 | 加强背景失焦、减少背景动作幅度 | 低 |

修复后重跑相关镜头与校验脚本，不要只在备注里说明。
