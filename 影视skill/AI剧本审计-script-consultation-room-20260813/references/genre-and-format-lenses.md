# 类型与格式透镜

## 短视频与竖屏短剧

检查前三秒、前十秒、第一次情绪回报、每个节拍的信息增量、预期变化、滑走点、反转、最终回报和追更钩子。把三秒和十秒标记视为审查窗口目标。只有当片长或时间码可靠时，才做秒级发现；否则用临时场景或节拍 ID 加原文锚点审查等价开场节拍，不估算也不声称精确秒数。识别被承诺问题在哪个确切节拍被打开、改变、延迟或兑现。不要把快速剪切当成叙事推进。

## 长片与长篇分集

检查场景目的、幕转折、单集任务、长线人物弧、A/B 故事互动、信息释放、集级回报和继续观看动力。不要把短视频密度强加给必要的沉浸、沉默或积累。

对长剧本，包括长片和长篇分集，按三层工作：

1. 构建非评价性的规范地图。
2. 结合理解所需上下文审查局部源文本段落。
3. 对每个 P0 和 P1 回到源文本复核。

## 类型提示

只应用与剧本及被审查具体段落相关的提示。健康评估中，无关维度标为 `N/A`；不要把 `N/A` 用作问题状态或证据类型。

- **现实/情感：** 行为真实、克制、关系历史、挣来的释放、余味。
- **悬疑：** 信息归属、线索公平性、误导项、因果揭示、重看价值。
- **喜剧：** 铺垫、升级、惊喜、节奏、基于人物的后果；不要只数笑点。
- **爱情：** 吸引证据、障碍可信度、选择、互惠、边界与同意。
- **复仇/爽感：** 委屈清晰度、压力积累、主体性、回报间距、升级成本。
- **家庭/伦理：** 相互竞争的正当需求、代际背景、非脸谱化冲突、情感诚实。
