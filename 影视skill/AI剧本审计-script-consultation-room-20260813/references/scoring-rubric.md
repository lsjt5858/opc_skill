# 评分量表

只在完成基于证据的诊断后评分。分数用于定位风险，绝不替代问题卡。

| 分数 | 锚点 |
| --- | --- |
| 0–2 | 严重失效；该维度无法执行基本戏剧功能。 |
| 3–4 | 存在明确实质性失败，且有重复证据。 |
| 5–6 | 基本可用，但有可识别限制。 |
| 7–8 | 强/可靠，只有轻微弱点。 |
| 9 | 卓越，且有多个具体优点。 |
| 10 | 罕见；只有在证据极强且该维度没有实质弱点时使用。 |
| N/A | 与格式、平台或所给节选无关。 |

## 健康维度

为每个适用维度评分并引用证据。

- `structure`：戏剧承诺、因果、升级、反转、高潮和解决。
- `character`：欲望、动机、主体性、可信度、关系和弧线。
- `rhythm`：有意义的预期变化、信息、压力和释放的速率与位置。
- `emotion`：情绪准备、推进、强度、回报、对照和余韵。
- `visual_storytelling`：可表演动作、调度、图像驱动的信息、视听表达和表演空间。
- `audience_propulsion`：钩子、活跃问题、悬念、信息增量、留存压力和继续观看欲。
- `producibility`：可行性、连续性、场景、群演、复杂动作、特效、声音和物料制作风险。

## 权重与报告

将健康度存储为 `dimensions`、`overall_score` 和 `overall_reason`。`dimensions` 必须且只能分别包含以下每一项：`structure`、`character`、`rhythm`、`emotion`、`visual_storytelling`、`audience_propulsion` 和 `producibility`。每项记录 `applicability`、`score`、`weight`、非空 `evidence`、`linked_issue_ids` 和 `linked_strengths`。

根据格式和用户声明目标动态设定权重。绝不要计算简单未加权平均。每个适用维度都必须有数值分。当下方规则要求权重时，用 5–35 之间的整数百分比表示。对每个维度，报告分数或 `N/A`、引用证据、最终权重或 null，以及简短权重理由。文字修改成本与物料制作风险必须分开。

适用维度表示为 `APPLICABLE`，无关或不可评估维度表示为 `N_A`。`N_A` 维度的 `score` 和 `weight` 均为 null，并从分母中排除。绝不要为无法评估的维度编造分数。

用适用维度和最终权重计算 `overall = Σ(score × weight) / 100`，再按四舍五入到一位小数。维度分仍来自上方证据锚点；总分不是成功概率。

当 `overall_score` 非 null 时，每个适用维度都需要权重，且权重总和必须为 100；校验器会验证披露的加权四舍五入计算。当 `overall_score` 为 null 且至少三个维度适用时，这些维度仍需最终权重且总和为 100。重新归一化适用权重前，先移除所有 `N_A` 维度。

当 `overall_score` 为 null 且只有一两个维度适用时，将所有适用权重设为 null：证据广度不足以形成总分，也无法满足有意义的 5–35 分配。请在 `overall_reason` 中解释。如果没有维度适用，则所有权重均为 null。无论哪种情况，适用维度仍必须有分数。

当超过半数维度为 `N_A`，或供应稿件过于不完整、无法支撑可辩护总分时，将 `overall_score` 设为 null。每个 `linked_issue_ids` 值必须解析到同一次会诊中的问题。7 分及以上视为高分；其 `linked_strengths` 必须包含至少一个受保护优点引用。低于 7 分不要求该链接。

健康分不会创建新问题。每个低分都必须指向现有问题 ID 或其引用证据。每个高分都必须指向纳入创作锁考虑的受保护优点。`N/A` 不是 0，绝不能拉低总分。
