# 乡村田园叙事视觉策划

## 目标

把节气、节日、地域、民族、农事、手艺或乡村生活主题，转化为有因果、有变化、可连续追更的视觉故事。先设计故事，再设计画面；人物数量服从事件，不为“热闹”或“统一”机械塞人。

## 核心原则

1. **事件驱动**：每一幕必须发生具体事件，避免仅替换背景的田园摆拍。
2. **人物按需**：允许无人空镜、单人、双人、小家庭、多人协作或村落群像；按镜头功能选择最少必要人数。
3. **农时合理**：作物状态、天气、光线、工具和劳动阶段必须匹配季节与地域。
4. **地域明确**：建筑、地貌、物产、服装、工具和饮食来自同一地域系统，不拼贴“泛中国风”。
5. **民俗尊重**：民族和地方仪式不得猎奇化、神秘化或随意混搭；未经核实的仪式细节不写成事实。
6. **连续可追**：同一系列保持时间线、空间图、道具状态和人物关系；镜头之间要有前因后果。
7. **去重优先**：主动避开当前系列和历史已用场景，不用“挑水、喂鹅、摘果、做饭”等高频动作反复充数。
8. **真实乡村**：允许泥、水、烟、汗、旧物、天气变化和劳动重量；不把乡村处理成无生产逻辑的精致布景。

## 工作流

### 0. 判断任务模式

- **新系列**：无历史资产，按下列完整流程建立世界锚点。
- **续集**：已有系列，先读取 `references/series-bible.md` 规则和项目内 `series-bible.json`，继承人物、地点和道具状态，只设计新任务与新变化，不重建设定。
- **修复**：已有分镜或成图出现问题，直接进入 `references/generation-troubleshooting.md`，只改问题项，不推翻整集。

### 1. 解析输入

提取或合理补全：

- 主入口：24节气 / 节日 / 地域民族 / 非遗手艺 / 四季生活 / 自定义事件。
- 地域：省域或自然地理区；民族题材还需具体民族与社区语境。
- 时间：季节、节气、一天时段、年代。
- 产物：故事梗概、镜头清单、Midjourney V7、Seedance 2.0/2.5、封面或发布文案。
- 数量与比例：默认15幕、16:9；用户另有要求时服从用户。
- 视觉：写实电影、纪实、胶片、诗意现实主义、绘画或其他明确风格。
- 连续资产：人物、院落、村路、作物、牲畜、工具、天气和关键道具。

只缺一个关键参数时合理默认并说明；地域、民族、时间与产物同时模糊且会改变事实时，一次问清。

### 2. 选择知识库

按需读取，不一次加载全部：

- 节气或四季农事 → `references/solar-terms.md`
- 节日、赶集、庙会、岁时仪式 → `references/festivals-folkways.md`
- 地域、村落建筑、民族题材 → `references/regions-ethnicities.md`
- 需要新事件、职业、手艺或生活冲突 → `references/rural-event-library.md`
- 需要连续分镜、人数决策、景别与去重 → `references/story-cinematography.md`
- 需要具体交付格式 → `references/output-templates.md`
- 需要查看完整15幕范例与人数分配 → `references/example-autumn-fair.md`
- 需要季度规划、选题排期、系列钩子或平台分发 → `references/series-production.md`
- 需要跨集人物、道具、地点一致性与历史去重 → `references/series-bible.md`
- 出图或出片阶段出现走形、崩坏、雷同、假仙气等问题 → `references/generation-troubleshooting.md`

涉及真实地域、民族、节庆、非遗传承或历史年代时，如参考库不足，先用公开可靠来源查证；把“已查证事实”和“创作性情节”分开。仅凭用户给定世界观创作时不强制检索。

### 3. 建立“世界锚点”

用6项锁定系列：

1. **地点锚点**：村庄类型、核心建筑、地貌、水系和交通。
2. **时间锚点**：节气、天气进程、日照方向、一天时间线。
3. **生产锚点**：主作物、家畜、工具、手艺或当日共同任务。
4. **人物锚点**：只定义会反复出现的核心人物；年龄必须为成年人或明确家庭儿童角色，服饰与职业相符。
5. **关系锚点**：家人、邻里、师徒、同伴、返乡者或村落协作关系。
6. **道具锚点**：贯穿故事的物件，例如一盏未完成的灯、一捆新麻、一只待修木船或一封集市订单。

不要求每幅图都出现全部锚点；只要求连续出现时状态一致。

### 4. 生成因果故事线

先写一句“任务句”：

> 谁在什么时间和地点，为了什么目标，需要完成什么事情，途中发生什么变化，最后留下什么结果或悬念。

15幕默认节奏：

1. 环境预告
2. 任务触发
3. 准备材料
4. 第一次行动
5. 技能/工艺细节
6. 协作或交接
7. 小成果
8. 天气、工具或人际变化
9. 应对变化
10. 扩大到田野或村落
11. 关键完成
12. 与他人连接
13. 集体或情绪高潮
14. 结果与余波
15. 安静收束或下一集钩子

这是节奏模板，不是固定剧情；根据主题可增减人物与公共场景。

### 5. 为每幕决定人物数量

先判断镜头目的，再选择人数：

- **0人**：天气、节气、空间转换、劳动痕迹、悬念预告、结果余韵。
- **1人**：专注手艺、独立判断、等待、赶路、内心情绪、体力劳动特写。
- **2人**：交接、教学、协作、对话、照料、轻松冲突。
- **3–5人**：家庭分工、小型制作、邻里互助、搬运、排练。
- **6人以上**：赶集、丰收、节庆、集体仪式、公共工程；必须有前中后景层次与明确主动作。

同一15幕建议至少包含：2–4个无人空镜、4–6个单人镜头、3–5个双人镜头、2–4个群像镜头。不要机械满足配额；故事需求优先。

### 6. 设计画面

每幕明确：

- 事件与动作起点
- 人物数量、身份和相互位置
- 景别、机位、镜头方向和前中后景
- 时间、天气、风向和光源
- 材质与劳动痕迹
- 情绪与表情
- 与上一幕的道具或空间连接
- 该幕结束后发生的状态变化

连续系列中，远景、中景、近景、特写交替；不要连续三幕使用相同景别或同一“站着做事”构图。

### 7. 输出提示词

使用 `references/output-templates.md` 的对应格式。通用要求：

- Midjourney V7 默认中英文各一条；英文是完整重写，不做逐字硬译。
- 每条提示词独立可用，同时重复必要的连续性锚点。
- 画面内无文字、无水印，除非用户明确要求可见文字。
- 用户指定比例、版本和参数时严格沿用；未指定默认16:9和V7 raw写实路线。
- 转视频时只描述从首帧可合理发生的运动，补充风、布料、植物、烟雾、水体和真实惯性；不得把3–5秒塞入过多事件。

### 8. 质量检查

可执行检查：把分镜整理成 JSON 后运行

```bash
python3 scripts/check_storyboard.py plan.json --expected 15 --history series-bible.json
```

关注 `errors`（必须清零）与 `warnings` 中的重复签名、相邻镜头雷同、人数或景别单一、跨集复用。

人工检查：

- 数量准确，中英文一一对应。
- 故事存在起因、推进、变化、结果。
- 每幕人物数量有理由，没有固定“双女主”惯性。
- 时间、天气、光线和作物阶段连续。
- 地域建筑、服装、工具、饮食不互相冲突。
- 民族与节庆元素已核实或明确为创作性设计。
- 与用户历史版本对比，重复场景不超过20%；若重复，必须承担新的剧情功能。
- 景别、机位和动作不连续重复。
- 群像不出现无目的人群；空镜不只是装饰。
- 续集已继承既有设定，并回应或明确延后上一集钩子。
- 提示词不含占位符、内部字段或无法执行的抽象口号。

## 风格入口

可组合但需保持同一世界逻辑：

- **24节气篇**：气候变化、物候、农事与家庭生活。
- **传统节日篇**：备节、制作、迎客、仪式、宴饮与散场。
- **地域乡村篇**：江南水乡、西南山地、黄土高原、北方平原、岭南水网、高原牧区等。
- **民族村寨篇**：以具体社区、节日、服饰和生产方式为依据，不做元素拼贴。
- **非遗手艺篇**：材料采集、工具准备、师徒工序、失败修正、成品进入生活。
- **乡村职业篇**：木匠、篾匠、茶农、船工、养蜂人、护林员、乡村医生、邮递员等。
- **乡村事件篇**：秋集、修桥、晒书、迎亲、戏班进村、暴雨抢收、候鸟到访、夜间寻畜等。
- **诗意空镜篇**：作为叙事节点插入，不单独堆砌审美词。

## 禁止模式

- 不默认每幕两位年轻女性。
- 不用所有角色穿统一飘逸古装来替代真实地域服饰。
- 不把24节气当作全国统一农事日历。
- 不混搭不同民族的服饰、建筑、乐器和仪式。
- 不连续复用挑水、喂鹅、摘果、做饭、追鸡、晒衣等高频动作。
- 不用过量薄雾、逆光、萤火、花瓣制造虚假“仙气”。
- 不让儿童承担危险劳动，不美化贫困或危险生产。
- 不把群众当无动作的背景填充物。

## 最小反馈

先给故事线和人物分配逻辑；用户确认后再生成大批量图像。用户只要提示词时，可直接交付完整提示词，不主动生成图片。
