# 输出模板

## A. 故事线提案

先输出：

1. 标题
2. 地域、季节/节气、年代、视觉风格
3. 一句任务句
4. 世界锚点
5. 15幕表格：编号、事件、人数、人物/主体、地点、景别、时间、承接关系
6. 与历史内容的去重说明

## B. Midjourney V7 中英文提示词

每组格式：

```markdown
## 01｜镜头标题

**人数与叙事作用**：0/1/2/群像；为什么需要这些人。

**中文提示词**

[地域与时间]，[具体空间]，[人物数量、年龄、身份、服装和位置]，[动作起点、受力与事件结果]，[关键道具状态]，[天气、风、光线]，[景别、机位、前中后景]，[真实材质与情绪]，真人实拍电影感，不摆拍，无文字，无水印 --ar 16:9 --v 7 --style raw --s 150

**English Prompt**

[Complete idiomatic English rewrite with the same factual anchors and visual logic] --ar 16:9 --v 7 --style raw --s 150
```

规则：

- 固定人物只在出现时描述；不要为了连续性强行让其出镜。
- 群像写明主动作、辅助动作和背景动作。
- 无人镜头写明叙事功能和前后状态。
- 用户提供seed时全套统一；未提供时不擅自编seed，除非用户要求可复现。
- 风格参数服从用户已有工作流；不确认的实验参数不添加。

## C. Seedance 2.0

```text
以对应图片作为首帧。5秒，16:9。

【镜头与动作】只安排一个主要事件和一个结果，说明人物/动物/环境的真实运动。

【环境】风、植物、烟、雨、水、布料等连续运动。

【表情与声音】按事件设计；没有叙事必要时只保留环境声。

【结尾缓冲】最后0.5秒自然减速，保留可剪辑稳定画面。

【统一约束】真人实拍；身份、服饰、建筑和道具稳定；真实速度、重力、摩擦和惯性；不新增主体，不穿模，不闪烁，不失重；无动画感、游戏感、光滑CG感；无字幕、文字、LOGO和水印。
```

## D. Seedance 2.5

```text
以对应图片作为首帧与唯一视觉锚点。5秒，16:9。

【0-1秒】建立空间和动作起点。
【1-3.2秒】完成主要动作，写清力量传递和环境反馈。
【3.2-4.5秒】产生结果与人物反应。
【4.5-5秒】自然减速留白。

【声音】环境声优先；对白或旁白仅在推动人物关系/悬念时加入短句。

【统一约束】真实真人实拍效果；人物、动物、服饰、建筑和道具稳定；真实物理运动、速度、力量、重力与惯性；不瞬移、不穿模、不抽搐、不闪烁、不失重；无廉价特效、动画感、游戏感、塑料皮肤或光滑CG感；无字幕、额外文字、LOGO和水印。
```

## E. 封面与发布内容

封面从高潮或悬念幕选取，不另造与正片无关场景。标题控制为主标题4–8字、副标题4–10字。发布文案按平台调整，但不得虚构真实民族、历史或节庆事实。
