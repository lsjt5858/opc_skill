# 乡村田园叙事视觉策划

## 产物边界

本 Skill **只产出文字提示词、故事策划与发布文案，不调用任何图片或视频生成工具**。即使用户描述的是画面或运动效果，也交付可直接复制使用的提示词。用户明确说“生成图片”“生成视频”时，离开本 Skill 进入对应生成流程；实际调用 Seedance 2.5 前必须另行读取并遵循 `seedance-25` Skill。

## 目标

把节气、节日、地域、民族、农事、手艺或乡村生活主题，转化为有因果、有变化、可连续追更的视觉故事，并输出可直接使用的提示词。先设计故事，再设计画面；人物数量服从事件，不为"热闹"或"统一"机械塞人。

## 默认风格

默认审美是**惬意唯美的东方田园生活感**：正在生活的古代中国乡村，温暖、松弛、有情绪。

- 人物穿日常汉服等具体形制服装，不是粗布苦难装，也不是仙侠飘带装。
- 事件以轻松生活为主：戏水、采莲、赶集、饮茶、晒谷、围坐吃饭。
- 光影走清晨与傍晚低角度阳光，暖金高光配清凉绿影。
- 允许劳动，但不渲染苦难、危险和贫困。

写任何提示词前必须先读 `references/visual-style.md` 与 `references/prompt-dimensions.md`。只有用户明确要求纪实、苦难、荒凉、暗黑或其他风格时，才覆盖本默认值。

## 核心原则

1. **只出提示词**：交付文字方案，不生成图像。
2. **事件驱动**：每一幕必须发生具体事件，避免仅替换背景的古装摆拍。
3. **六维度组装**：民族、地域、着装、风俗场景、事件、人物结构逐项写明。
4. **人物按需**：允许无人空镜、单人、双人、小家庭、多人协作或村落群像；按镜头功能选择最少必要人数。
5. **惬意优先**：默认呈现松弛生活气息，情绪具体可感。
6. **地域明确**：建筑、地貌、物产、服装、工具来自同一地域系统，不拼贴"泛中国风"。
7. **民俗尊重**：民族和地方仪式不得猎奇化、神秘化或随意混搭；未经核实的仪式细节不写成事实。
8. **连续可追**：同一系列保持时间线、空间、道具状态和人物关系。
9. **去重优先**：主动避开历史已用场景，不用高频动作反复充数。

## 工作流

### 0. 判断任务模式

- **新系列**：无历史资产，按下列完整流程建立世界锚点。
- **续集**：已有系列，先读取 `references/series-bible.md` 规则和项目内 `series-bible.json`，继承人物、地点和道具状态，只设计新任务与新变化，不重建设定。
- **修复**：已有分镜或成图出现问题，直接进入 `references/generation-troubleshooting.md`，只改问题项，不推翻整集。
- **图片转视频**：完整正片图片提示词与封面图设计已收纳，读取 `references/seedance-storyboard-publishing.md`，只将正片图片逐幕转成Seedance 2.5视频提示词；封面图不进入正片分镜计数。
- **发布收尾**：完整视频分镜已收纳，依据同一故事、封面设计与镜头结果，核验平台当前规则，分别输出抖音、快手、小红书、微信视频号和B站独立发布包；不得把同一通用文案仅替换平台名。

### 1. 解析输入

提取或合理补全：

- 主入口：24节气 / 节日 / 地域民族 / 非遗手艺 / 四季生活 / 自定义事件。
- 地域：省域或自然地理区；民族题材还需具体民族与社区语境。
- 时间：季节、节气、一天时段、年代。
- 产物：故事梗概、镜头清单、Midjourney V7、Seedance 2.0/2.5、封面或发布文案。
- 数量与比例：默认15幕、16:9；用户另有要求时服从用户。
- 视觉：写实电影、纪实、胶片、诗意现实主义、绘画或其他明确风格。
- 连续资产：人物、院落、村路、作物、牲畜、工具、天气和关键道具。

只缺一个关键参数时合理默认并说明；地域、民族、时间与产物同时模糊且会改变事实时，一次问清。

### 2. 选择知识库

**必读**（每次写提示词前）：

- 色调、质感、构图、人物情绪基准 → `references/visual-style.md`
- 六维度组装顺序、事件库、中英文模板 → `references/prompt-dimensions.md`

按需读取：

- 节气或四季农事 → `references/solar-terms.md`
- 节日、赶集、庙会、岁时仪式 → `references/festivals-folkways.md`
- 地域、村落建筑、民族题材 → `references/regions-ethnicities.md`
- 需要新事件、职业、手艺或生活冲突 → `references/rural-event-library.md`
- 需要连续分镜、人数决策、景别与去重 → `references/story-cinematography.md`
- 需要具体交付格式 → `references/output-templates.md`
- 需要在图片提示词阶段设计故事封面、故事名称叠字与横竖版安全区 → `references/cover-design.md`
- 需要复制前兼容性校验、平台参数规则或错误分级 → `references/prompt-validation.md`
- 已收纳图片提示词，需要转Seedance 2.5逐镜视频提示词与整片组装 → `references/seedance-storyboard-publishing.md`
- 视频分镜已收纳，需要按抖音、快手、小红书、微信视频号、B站等当前规则分别生成发布包 → `references/platform-publishing.md`
- 需要查看完整15幕范例与人数分配 → `references/example-autumn-fair.md`
- 需要惬意风格的成品提示词语感基准 → `references/example-jiangnan-summer.md`
- 需要季度规划、选题排期、系列钩子或平台分发 → `references/series-production.md`
- 需要跨集人物、道具、地点一致性与历史去重 → `references/series-bible.md`
- 提示词效果不稳定、人物走形、群像崩坏、风格跑偏 → `references/generation-troubleshooting.md`

涉及真实地域、民族、节庆、非遗传承或历史年代时，如参考库不足，先用公开可靠来源查证；把“已查证事实”和“创作性情节”分开。仅凭用户给定世界观创作时不强制检索。

### 3. 建立“世界锚点”

用6项锁定系列：

1. **地点锚点**：村庄类型、核心建筑、地貌、水系和交通。
2. **时间锚点**：节气、天气进程、日照方向、一天时间线。
3. **生产锚点**：主作物、家畜、工具、手艺或当日共同任务。
4. **人物锚点**：只定义会反复出现的核心人物；年龄必须为成年人或明确家庭儿童角色，服饰与职业相符。
5. **关系锚点**：家人、邻里、师徒、同伴、返乡者或村落协作关系。
6. **道具锚点**：贯穿故事的物件，例如一盏未完成的灯、一捆新麻、一只待修木船或一封集市订单。

不要求每幅图都出现全部锚点；只要求连续出现时状态一致。

### 4. 生成因果故事线

先写一句“任务句”：

> 谁在什么时间和地点，为了什么目标，需要完成什么事情，途中发生什么变化，最后留下什么结果或悬念。

15幕默认节奏：

1. 环境预告
2. 任务触发
3. 准备材料
4. 第一次行动
5. 技能/工艺细节
6. 协作或交接
7. 小成果
8. 天气、工具或人际变化
9. 应对变化
10. 扩大到田野或村落
11. 关键完成
12. 与他人连接
13. 集体或情绪高潮
14. 结果与余波
15. 安静收束或下一集钩子

这是节奏模板，不是固定剧情；根据主题可增减人物与公共场景。

### 5. 为每幕决定人物数量

先判断镜头目的，再选择人数：

- **0人**：天气、节气、空间转换、劳动痕迹、悬念预告、结果余韵。
- **1人**：专注手艺、独立判断、等待、赶路、内心情绪、体力劳动特写。
- **2人**：交接、教学、协作、对话、照料、轻松冲突。
- **3–5人**：家庭分工、小型制作、邻里互助、搬运、排练。
- **6人以上**：赶集、丰收、节庆、集体仪式、公共工程；必须有前中后景层次与明确主动作。

同一15幕建议至少包含：2–4个无人空镜、4–6个单人镜头、3–5个双人镜头、2–4个群像镜头。不要机械满足配额；故事需求优先。

### 6. 设计画面

每幕明确：

- 事件与动作起点
- 人物数量、身份和相互位置
- 景别、机位、镜头方向和前中后景
- 时间、天气、风向和光源
- 材质与劳动痕迹
- 情绪与表情
- 与上一幕的道具或空间连接
- 该幕结束后发生的状态变化

连续系列中，远景、中景、近景、特写交替；不要连续三幕使用相同景别或同一“站着做事”构图。

### 7. 输出提示词

使用 `references/prompt-dimensions.md` 的模板与 `references/output-templates.md` 的交付结构。通用要求：

- 默认中英文各一条；英文按同一顺序自然重写，不逐字硬译。
- 每条提示词独立可用，同时重复必要的连续性锚点。
- 六维度逐项写明：民族、地域、着装形制、风俗场景、事件动作、人物结构。
- 画面内无文字、无水印，除非用户明确要求可见文字。
- 未指定平台时输出通用纯文本，不附 `--` 参数；仅在明确使用 Midjourney 时追加其支持的参数，默认可用 `--ar 16:9 --style raw --stylize 175`。
- 正片图片提示词完成后必须按 `references/cover-design.md` 额外输出 1 张故事封面设计：默认显示故事名称，但通过“净底封面提示词＋后期叠字规范”实现；用户明确要求模型直接生字时才补带字版提示词。
- 封面优先取既有高潮、转折或情绪镜头重新构图，不另造故事事实；封面不计入正片图片数量，也不自动转换为Seedance正片镜头。
- 负面约束按镜头实际问题选 2–4 项，不固定堆叠完整长尾。
- 转视频时只描述从首帧可合理发生的运动，补充风、布料、植物、烟雾、水体和真实惯性；不得把3–5秒塞入过多事件。
- 当完整图片提示词已收纳时，不停在图片提示词阶段：按 `references/seedance-storyboard-publishing.md` 自动生成一一对应的Seedance 2.5视频分镜提示词。
- 当完整视频分镜提示词已收纳时，必须读取 `references/platform-publishing.md`，核验当前规则后分别输出抖音、快手、小红书、微信视频号、B站发布包；用户另点名的平台按核验结果追加。
- 各平台文案必须独立适配标题、正文结构、标签、互动和发布字段，不得只把同一文案更换平台名称。
- AI生成／合成内容必须附显著声明并提醒使用平台提供的AI标识入口；不得将虚构人物和情节包装成真实纪实。
- 文案紧扣本集人物、目标、变化与结果；封面只取既有镜头，并与图片阶段的封面设计一致。
- 上述“自动继续”只生成文字内容，不代表自动调用视频生成工具；用户要求实际生成时，必须另读 `seedance-25` Skill并获取生成前确认。
- 只交付文字，不调用生图或生视频工具。

### 8. 质量检查

先做提示词复制前预检：

```bash
python3 scripts/check_prompts.py prompts.json --platform generic
```

- 平台值按实际选择 `generic`、`midjourney`、`seedream` 或 `seedance`；未指定平台时必须使用 `generic`。
- `error` 必须清零；`warning` 默认只提醒，不因风格偏好自动阻断或批量删词。
- 只有用户明确要求零告警时才追加 `--strict`。
- 具体规则与最小改写方法见 `references/prompt-validation.md`。
- 本地预检不模拟平台在线审核，不得承诺“一定过审”。

分镜可执行检查：把分镜整理成 JSON 后运行

```bash
python3 scripts/check_storyboard.py plan.json --expected 15 --history series-bible.json
```

图片→视频→发布的完整交付包可整理为 JSON 后运行：

```bash
python3 scripts/check_delivery_package.py delivery.json
```

交付包至少包含 `image_prompts`、`cover`、`video_prompts`、`publishing`；`publishing` 下默认包含 `douyin`、`kuaishou`、`xiaohongshu`、`wechat_channels`、`bilibili` 五个平台对象。正片图片与视频镜头ID和顺序必须一一对应，发布字段规范见 `references/platform-publishing.md`。

关注 `errors`（必须清零）与 `warnings` 中的重复签名、相邻镜头雷同、人数或景别单一、跨集复用。

人工检查：

- 数量准确，中英文一一对应。
- 六维度齐全：民族、地域、着装形制、风俗场景、事件、人物结构。
- 风格落在惬意唯美区间，未跑向纪实苦难或仙侠飘逸。
- 色彩在主色系内，未整体泛黄。
- 每条含具体动作、情绪、材质与空气感；负面约束只保留当前镜头必要项。
- 目标平台已明确；未明确时交付通用纯文本，不附平台私有参数。
- 提示词预检 `error` 为零；`warning` 已人工判断且未机械删改创作内容。
- 故事存在起因、推进、变化、结果。
- 每幕人物数量有理由，没有固定"双女主"惯性。
- 时间、天气、光线与季节连续。
- 地域建筑、服装、工具不互相冲突。
- 民族与节庆元素已核实或明确为创作性设计。
- 与用户历史版本对比，重复场景不超过20%。
- 景别、机位和动作不连续重复。
- 群像不出现无目的人群；空镜不只是装饰。
- 续集已继承既有设定，并回应或明确延后上一集钩子。
- 提示词不含占位符、内部字段或无画面信息的空洞形容。
- 正片图片提示词完成后，已额外交付 1 张封面图设计、净底提示词与故事名称叠字规范；封面未计入正片镜头。
- 图片提示词已收纳时，视频分镜数量与正片图片数量一一对应，每镜只有一个主要动作和一个直接结果。
- 视频分镜已收纳时，发布包默认包含抖音、快手、小红书、微信视频号、B站五个平台。
- 每个平台均有独立标题、正文／简介、标签、互动、封面信息、AI声明和发布前勾选项。
- 发布包中的封面标题、封面副标题和封面镜头与图片阶段的封面设计一致。
- 各平台文案确实复用了故事中的具体人物、目标、变化和结果，不是泛化田园文案，也不是同文换平台名。
- 已记录规则核验日期、官方来源与未核实项；编辑建议未冒充平台硬限制。
- 未调用生图或生视频工具，只交付文字。

## 风格入口

可组合但需保持同一世界逻辑：

- **24节气篇**：气候变化、物候、农事与家庭生活。
- **传统节日篇**：备节、制作、迎客、仪式、宴饮与散场。
- **地域乡村篇**：江南水乡、西南山地、黄土高原、北方平原、岭南水网、高原牧区等。
- **民族村寨篇**：以具体社区、节日、服饰和生产方式为依据，不做元素拼贴。
- **非遗手艺篇**：材料采集、工具准备、师徒工序、失败修正、成品进入生活。
- **乡村职业篇**：木匠、篾匠、茶农、船工、养蜂人、护林员、乡村医生、邮递员等。
- **乡村事件篇**：秋集、修桥、晒书、迎亲、戏班进村、暴雨抢收、候鸟到访、夜间寻畜等。
- **诗意空镜篇**：作为叙事节点插入，不单独堆砌审美词。

## 禁止模式

- 不调用生图或生视频工具替代文字提示词与文案交付。
- 不默认每幕两位年轻女性。
- 不写"古装"而不给形制；不用纱质飘带、发光材质、影视重妆。
- 不把24节气当作全国统一农事日历。
- 不混搭不同民族的服饰、建筑、乐器和仪式。
- 不连续复用挑水、喂鹅、摘果、做饭、追鸡、晒衣等高频动作。
- 不用过量薄雾、逆光、萤火、花瓣制造虚假"仙气"。
- 不渲染苦难、危险劳动和贫困；不让儿童承担危险动作。
- 不把群众当无动作的背景填充物。
- 不写"美丽""绝美""仙气飘飘"等无画面信息的形容。

## 最小反馈
