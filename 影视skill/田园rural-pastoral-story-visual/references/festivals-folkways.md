# 节日与岁时民俗叙事库

## 原则

1. 先确定地域与家庭/社区，再选食物、服饰和仪式。
2. 把节日拍成“准备—发生—散场”，不要只拍盛装合影。
3. 仪式核心动作、参与资格、禁忌和器物不确定时先查证。
4. 宗教性、祭祀性和民族性活动保持尊重，不制造神秘恐怖效果。

## 通用叙事单元

- **节前准备**：扫屋、修器、采买、浸泡原料、染布、扎灯、排练、备礼。
- **共同制作**：包食物、糊灯、印年画、编花环、搭戏台、装饰船只。
- **迎客与归乡**：渡口等船、车站接人、村口挂灯、整理客房。
- **公共事件**：巡游、赛舟、社戏、歌会、摆集、祭祖、敬老。
- **微观细节**：手部工序、旧器物、儿童旁观、老人指导、后台准备。
- **散场余韵**：收灯、扫纸屑、熄火、送客、空戏台、第二天清晨。

## 节日方向

| 主题 | 可用事件链 | 需要地域化 |
|---|---|---|
| 春节 | 赶年集→磨豆腐/蒸食→贴春联→守岁→拜年→收灯 | 年食、祭祀、舞龙舞狮并非处处相同 |
| 元宵 | 扎灯→试灯→挂灯→猜谜/灯会→散场收灯 | 灯型、巡游形式 |
| 清明 | 备供→行山路→祭扫→植树/插柳→归家做时食 | 祭扫礼序、时食 |
| 端午 | 采叶→浸米→包粽→制香囊→赛舟/祭祀→晾桨 | 粽形、龙舟和祭仪 |
| 七夕 | 染甲、乞巧、晒书、做巧果、夜观星 | 地方乞巧形式 |
| 中秋 | 打月饼/做时食→采桂→摆桌→候月→送客 | 月饼与祭月形式 |
| 重阳 | 做糕→备菊酒→登高→敬老→归家 | 地域山地条件与礼俗 |
| 腊八 | 选豆→淘洗→熬粥→赠邻→腌蒜 | 食材与赠粥习惯 |
| 冬至 | 磨粉/和面→家庭制作→祭祖/团聚→夜谈 | 南北及地方食品差异 |
| 秋集/冬集 | 整货→修摊→赶路→开市→交易→戏班→散集 | 商品、交通、交易方式 |

## 群像设计

群像必须分工：主动作1个，辅助动作2–3个，背景动作若干。例如“秋集”不是所有人站着逛，而是：前景称粮，中景修灯，后景木船靠岸，儿童追纸轮，老人坐摊后喝茶。
