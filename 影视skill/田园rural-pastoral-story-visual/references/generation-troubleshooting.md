# 生成排错与一致性

## 一致性优先级

当画面元素冲突时，按以下顺序保证：

1. 人物身份与年龄
2. 服装颜色与形制
3. 关键道具状态
4. 空间结构与建筑
5. 天气与光线
6. 氛围与美感

美感不得压过前四项。

## 常见失败与修法

| 问题 | 表现 | 修法 |
|---|---|---|
| 人物走形 | 五官、年龄、体型跨镜变化 | 减少同框人数，缩短人物描述并前置，固定“成年、发型、服装颜色”三要素 |
| 服装漂移 | 颜色或形制自行改变 | 用具体色名和材质，避免“古风”“飘逸”等模糊词 |
| 道具突变 | 灯、船、工具形状或状态改变 | 每次重复道具的材质、尺寸参照物和当前状态词 |
| 多人崩坏 | 群像出现畸形肢体或粘连 | 拉远景别、增加遮挡、明确前中后景分层，减少清晰面孔数量 |
| 手部错误 | 手指数量或握持异常 | 让手与工具交互并被部分遮挡，避免张开手掌特写 |
| 农事错误 | 作物与季节不符 | 明确生长阶段词，如抽穗、灌浆、待割、已割 |
| 画面太干净 | 缺乏生产痕迹 | 添加泥点、磨损、旧漆、湿痕、工具堆放 |
| 假仙气 | 过量雾、光斑、花瓣 | 保留单一光源逻辑，删除装饰性粒子 |
| 构图雷同 | 连续多幕站立中景 | 改机位高度、改人物朝向、改前景遮挡 |
| 文字乱码 | 招牌、灯笼出现错字 | 默认写明无文字；确需文字时后期添加 |

## 提示词写作顺序

推荐固定顺序，便于批量控制：

1. 时间与地域
2. 具体空间与建筑
3. 人物数量与身份
4. 动作起点与受力
5. 关键道具与状态
6. 天气、风向、光源
7. 景别、机位、层次
8. 材质与情绪
9. 风格与负面约束
10. 参数

单条提示词建议不超过约120个中文词组；超长会稀释关键约束。

## 批量出图流程

1. 先出第1幕，确认人物与空间。
2. 再出冲突最强的一幕，验证动作可还原度。
3. 通过后再批量生成其余镜头。
4. 同幕保留至少2个候选，按“人物正确 > 动作正确 > 构图 > 美感”排序。
5. 出现连续失败时，先降低同框人数或改景别，再调整措辞。

## 图生视频衔接

- 图片停在动作起点，不要把动作画完。
- 单镜只安排一个主要动作和一个结果。
- 明确风向、布料、水体和烟尘的运动方向。
- 群像镜头中限制运动主体数量，其余作环境运动。
- 结尾保留减速与稳定画面，方便剪辑。

## 内容安全

- 不生成危险劳动示范，尤其涉及儿童、高空、明火和机械。
- 不虚构真实民族仪式细节。
- 不使用真实姓名、商标、门牌等可识别信息。
- 涉及宗教或祭祀空间时保持克制，避免不当动作。
