# 季播运营与选题排期

## 系列层级

- **单集**：15幕，一个明确任务，独立可看。
- **季**：8–15集，共享地点、人物库、生产线索和一条季度悬念。
- **年**：以节气或农事循环为主轴，跨季承接同一村庄的变化。

## 季度骨架

1. **开季集**：建立地点、核心人物、当季主要任务，结尾抛出季度目标。
2. **推进集**：每集完成一个阶段任务，同时暴露一个新问题。
3. **压力集**：天气、损坏、缺料、人手不足或时间紧迫造成明显阻力。
4. **转折集**：外来者、返乡者、订单、迁徙动物或旧物件带来新变量。
5. **高潮集**：公共事件，如集市、节庆、抢收、通桥、开窑、演出。
6. **收季集**：结果落地，人物关系变化，留下下一季钩子。

同一季内避免连续两集使用同类高潮，例如连续两集都以夜间点灯收尾。

## 选题日历

按“节气 + 生产阶段 + 公共事件”组合排期：

| 周期 | 选题来源 | 说明 |
|---|---|---|
| 每月 | 当月两个节气 | 物候变化和农事阶段 |
| 每季 | 一次传统节日或地方节庆 | 提供群像高潮 |
| 每季 | 一项手艺或工程 | 提供跨集连续任务 |
| 不定期 | 天气事件与意外 | 提供压力集素材 |
| 不定期 | 人物事件 | 返乡、学艺、送别、迎新 |

发布前确认三点：节气是否已过、事件是否与当地气候矛盾、是否与近30天已发布内容重复。

## 系列钩子设计

每集结尾从以下类型中选择，且相邻集不重复：

- 物件钩子：出现来历不明的器物。
- 人物钩子：有人到达或离开。
- 任务钩子：新的时间限制或订单。
- 环境钩子：天气、河水、山火、候鸟等变化。
- 关系钩子：合作出现分歧或和解。
- 悬念钩子：远处灯火、脚印、船只、声音。

## 平台适配

- **横版长叙事**：完整15幕，适合成片和合集。
- **竖版切片**：从15幕中选出3–5个强动作幕重构为竖版，注意重新设计构图，不直接裁切。
- **封面**：选高潮幕或悬念幕，保证主体清晰、动作可读。
- **标题**：地点或事件 + 冲突或变化，避免纯抒情词堆砌。
- **系列名**：固定前缀 + 集数 + 单集主题，方便追更。

## 数据反馈迭代

关注四类信号并调整下一集：

1. 完播下降点 → 检查该段是否节奏拖沓或缺少事件。
2. 高互动画面 → 强化同类事件、人物关系或场景。
3. 评论提问 → 转化为下一集剧情或答疑镜头。
4. 重复审美疲劳反馈 → 更换地点、天气、时间段或人物组合。

不要因为单集数据好就把同一场景连续复制三集以上。
