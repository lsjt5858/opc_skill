# 乡村事件与职业库

用于避免高频“挑水、喂鹅、摘果、做饭”重复。选择事件时先匹配地域、季节、年代与真实生产条件。

## 材料与制作

- 割芦苇、晒蒲草、剥麻、绩麻、纺线、染布、晾染、补网
- 劈篾、刮篾、编筐、扎灯、糊纸、制风筝、编草鞋
- 和泥、制坯、装窑、开窑、修瓦、补墙、刷石灰
- 选木、刨木、打榫、修农具、修船、修戏箱、修钟表
- 采蜂蜡、浇烛、制香、磨墨、刻版、印年画、装订族谱/旧书
- 炒茶、揉茶、晾茶、制酱、封坛、榨油、磨粉、晒面

## 农林牧渔

- 选种、晒种、育苗、嫁接、压枝、疏果、套袋、护霜
- 清沟、筑埂、修渠、看水、夜灌、补秧、扶倒伏作物
- 养蜂、移蜂箱、查蜂脾、取蜜、熬蜡
- 放蚕、采桑、上蔟、缫丝
- 补渔网、放地笼、抬鱼篓、开渔、修船桨
- 赶羊转场、修圈、铺草、剪毛、打草、盐水饮畜
- 护林巡山、标记古树、清理风倒木、修防火带

## 家庭与社区

- 整理祖屋、晒书、补被、换窗纸、封窗、扫屋脊
- 村口接人、河埠迎船、送新粮、邻里借工具、归还器物
- 修桥、铺石路、抬长凳、搭戏台、挂灯、架幕、排练
- 乡村医生出诊、邮递员渡河、护林员夜巡、教师家访
- 雨前抢收、暴雨后清淤、风后扶树、雪后通路、停电点灯
- 老人教手艺、年轻人第一次独立完成、返乡者重新学习

## 市集与节庆

- 整理摊货、称粮、写价签（画面不必生成文字）、装船、赶路
- 试灯、挂灯、点灯、收灯、修灯、分灯油
- 戏班进村、开箱、熨戏服、调弦、试鼓、后台候场、散场收箱
- 皮影雕刻、上色、穿杆、挂幕、点灯、操偶
- 赛前修桨、绑鼓、抬船、赛后晾桨
- 迎亲前布置、送嫁、回门、宴后清理（需地域查证）

## 可持续系列钩子

- 一件未完成的器物跨3–5幕逐步完成。
- 一场天气变化迫使计划改变。
- 一位新人向老人学习，最后独立完成。
- 一条村路/桥/渠从损坏到恢复使用。
- 一艘船、一只蜂箱、一口窑或一个戏台串联多人关系。
- 集市订单、远方来信、候鸟到访或返乡者带来下一集任务。

## 去重方法

为每幕记录四元组：`地点 + 主动作 + 人物关系 + 关键道具`。与历史场景有三项相同时视为重复；保留同一地点时必须更换主动作和剧情功能。
