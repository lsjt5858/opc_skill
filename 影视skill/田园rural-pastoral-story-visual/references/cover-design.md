# 故事封面图设计

## 位置与触发

封面属于“图片提示词”阶段的固定收尾项。完整故事图片提示词完成后，必须额外输出 1 张封面图设计与提示词；封面不计入正片镜头数量，也不自动转换为 Seedance 2.5 正片分镜。

默认顺序：

```text
故事分镜图片提示词 → 封面图设计 → Seedance 2.5正片分镜 → 发布包
```

## 设计目标

封面应让用户在缩略图尺寸下立即看懂三件事：

1. 这是哪个故事：显示故事名称。
2. 核心事件是什么：选取本集高潮、转折或悬念动作。
3. 情绪是什么：人物关系、动作和色调与正片一致。

不得另造正片中不存在的人物、道具、地点或事件。可基于既有镜头重新构图，但不能改变故事事实。

## 默认选帧逻辑

按优先级选择：

1. **高潮动作**：水花、奔跑、集体完成、揭晓结果等，动作轮廓清楚。
2. **转折瞬间**：意外发生前后、人物回头、道具状态变化。
3. **情绪近景**：人物关系明确，表情自然，适合较安静的故事。
4. **悬念空镜**：仅在故事主体不是人物或人物画面不适合作封面时使用。

候选镜头多人或动作过密时，减少次要人物、拉开层次或改为中近景；封面仍保持原人物身份、服装和道具状态。

## 画幅与安全区

- 未指定平台时，默认先交付 `16:9` 横版封面，并说明可重构为 `9:16`，不是直接裁切。
- 横版：主体放在画面右侧或下方三分区，左上或左中保留标题安全区。
- 竖版：主体位于中下部，顶部约 20%–28% 保留标题安全区，避开人物脸部和关键动作。
- 标题、安全区和主体之间保留清晰层次；缩略图下避免细碎背景穿过文字区域。

## 故事名称与文字策略

封面必须显示故事名称，默认使用正式故事名作为主标题：

- 主标题建议 4–8 个汉字；故事名更长时，优先保留辨识度最高的核心短名，并把完整故事名放入副标题或发布标题。
- 副标题可选，4–10 个字，只补充事件或悬念，不重复主标题。
- 标题文案必须与发布包中的封面标题一致。

### 两层交付，避免生成文字乱码

默认同时交付以下两项：

1. **净底封面提示词**：画面内不直接生成文字，但明确预留标题安全区；适合先生成稳定画面，再后期叠字。
2. **叠字规范**：给出主标题、副标题、位置、颜色、字体气质、字号层级、描边／底衬方案。

若用户明确要求模型直接生成带字封面，再补充“带字版提示词”，并用中文引号标出准确文字；同时提醒生成模型可能出现错字，最终发布前应人工核字。Midjourney 默认采用净底＋后期叠字，不把中文标题直接写入生成提示词。

## 视觉规则

- 延续正片的色板、光源、材质和人物造型。
- 主体优先 1–3 人；群像只保留主动作承担者和必要反应者。
- 人脸、眼神、手部与关键道具不能被标题覆盖。
- 标题区域降低细节密度，可用雾化远景、白墙、天空、水面暗部或虚化稻田承载文字。
- 使用米白或暖白字时，搭配黛绿／灰蓝半透明底衬或轻描边；陶土红只作小面积强调。
- 不使用霓虹、金属立体字、强发光字、现代综艺贴纸或与正片冲突的高饱和配色。

## 输出模板

```markdown
# 封面图｜[故事名称]

**选帧依据**：取自第[编号]镜的[高潮／转折／情绪]，原因是[缩略图可读性与故事代表性]。
**画幅**：[16:9／9:16]
**主标题**：[故事名称或核心短名]
**副标题**：[可选]

## 净底封面提示词

[延续正片人物、地点、服装、动作、色调与材质；重新安排主体与标题安全区；画面无文字、无水印；按目标平台追加参数。]

## 叠字规范

- 主标题：[准确文字]
- 副标题：[准确文字／无]
- 位置：[安全区位置与对齐]
- 字体气质：[宋体／手写宋意／克制书卷感等，不指定无授权字体]
- 颜色：[正文色＋描边或底衬]
- 层级：[主标题明显大于副标题]
- 避让：[人物脸、手、关键道具、水花方向]

## 带字版提示词（仅用户要求时）

[用中文引号标出“主标题”和“副标题”，并要求文字准确清晰；不得与净底版混淆。]
```

## 与视频和发布包的关系

- 封面图不计入正片图片数量，不生成对应的 5 秒视频镜头。
- 发布包的 `cover_title`、`cover_subtitle`、`cover_scene` 必须与封面图设计一致。
- 若发布平台改为竖版，重新设计一条 9:16 封面提示词与叠字安全区，不直接裁切横版。

## 检查

- 是否明确显示故事名称的叠字方案。
- 是否有一条可直接生成的净底封面提示词。
- 是否说明封面取自哪个既有镜头或故事节点。
- 是否避开人物脸部、手部、关键道具和动作方向。
- 是否与正片人物、服装、道具、地点、天气和色调一致。
- 是否明确封面不计入正片镜头、不进入Seedance逐镜转换。
