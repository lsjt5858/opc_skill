## 风格定义

一句话概括：**以第三人称旁观为主视角，用背影、侧脸、手部和环境细节讲述一个人被时间改变的故事，节奏缓慢但情绪密度高，靠重复母题和跨年蒙太奇制造时间重量。**

与纯 POV 的区别：

| 维度 | 纯 POV | 情感叙事风格 |
|---|---|---|
| 观众身份 | "我就是主角" | "我在看着这个人" |
| 主视角 | 叙事者眼睛高度 | 跟拍/旁观/侧拍 |
| 面部信息 | 看不到主角脸 | 侧脸和局部特写是情绪核心 |
| 节奏 | 快推进 | 慢，允许长停留 |
| 片长 | 通常 ≤60s | 2–4 分钟可行 |
| 旁白 | 补充不可见信息 | 是叙事主体，画面是旁白的视觉化 |
| 转场 | 身体动作驱动 | 同构图匹配、时间流逝、黑场 |

## 核心镜头语言

### 1. 背影跟随（主力镜头，占全片 30–40%）

这是博主的标志性镜头，也是本风格的默认主视角。

- **画面**：镜头在人物身后 1.5–3m，跟拍行走、奔跑、站定，能看到后脑、肩背、手臂摆动和前方环境。
- **用途**：建立空间、推进时间、表达"在路上"的孤独感。
- **变体**：
  - 远景背影（3–5m，人物占画面 1/4）：表达渺小与环境压迫；
  - 中景背影（1.5–2m，人物占画面 1/2）：日常跟随，最常用；
  - 近景背影（0.8–1m，只剩肩背和后脑）：亲密或紧迫。
- **提示词写法**：`从人物身后约两米处跟随拍摄，可见[服装后背特征]和[随身物]，前方是[环境描述]，[光线]，自然行走节奏，轻微手持感，[情绪]`

### 2. 侧脸旁观（情绪积累镜头，占全片 15–20%）

- **画面**：人物侧脸 45°–90°，能看到表情但不直视镜头。
- **用途**：沉默中的情绪变化、看到重要信息的反应、做决定前的犹豫。
- **提示词写法**：`人物侧脸45度，可见[面部情绪特征]，背景[虚化描述]，[光线]，沉默克制，电影级侧光`

### 3. 手部特写（情感载体，占全片 10–15%）

- **画面**：手部独立占据画面，与道具互动。
- **用途**：不靠脸也能传情——握紧、松开、颤抖、抚摸都是情绪。
- **提示词写法**：`[左/右]手[动作描述]，[道具细节]，[皮肤纹理]，[光线]，极浅景深，手部情感特写`

### 4. 环境空镜（呼吸镜头，占全片 10–15%）

- **画面**：无人物，只有场景、光影、天气或道具静物。
- **用途**：段落间换气、时间暗示、情绪沉淀。
- **提示词写法**：`空镜，[场景描述]，[时间光线]，[天气/氛围细节]，无人，极静，[情绪暗示]`

### 5. 情绪特写（高潮镜头，全片不超过 3 次）

- **画面**：面部局部（眼角、嘴角、泪痕）或全身微动作（肩膀颤抖、手攥紧）。
- **用途**：情绪爆发点，全片只给 2–3 次，每次 ≤2 秒。
- **提示词写法**：`[面部局部]特写，可见[情绪生理特征]，[光线]，极浅景深，电影级微距质感`

### 6. 越肩旁观（对话镜头，占全片 5–10%）

- **画面**：从人物肩膀后方看向其面对的人或物。
- **用途**：对话、对峙、观看远方目标。
- **提示词写法**：`从人物[左/右]肩后方看向[对面人物/物体]，肩部占画面边缘，[距离描述]，[光线]`

### 7. POV 片段（可选，占全片 0–10%）

- **画面**：叙事者眼睛高度，有身体证据。
- **用途**：极少数沉浸式关键时刻，如拿起重要物品、推开关键门。
- **使用限制**：不作为主视角，只在需要"观众变成主角"的 1–2 个瞬间使用。

### 8. 跨年蒙太奇（时间转场，占全片 5–10%）

- **画面**：同一动作在不同年份重复，背景/服装/光线变化但构图不变。
- **用途**：压缩数年时间，让观众感受"一切都在变，只有这件事没变"。
- **提示词写法**：`与前一镜完全相同的构图和动作，[年份]已变为[新年份]，[背景变化]，[服装变化]，[光线变化]，人物姿态不变`

## 影调体系

情感叙事的核心是"色彩即情绪"。为每个叙事阶段定义色温、饱和度和对比度：

| 叙事阶段 | 色温 | 饱和度 | 对比度 | 光线质感 | 情绪 |
|---|---|---|---|---|---|
| 幸福回忆 | 暖黄 3200K | 中高 | 中低 | 柯达柔光、胶片颗粒 | 温暖、安全 |
| 失去瞬间 | 中性 4500K | 骤降 | 骤升 | 硬光、阴影加重 | 失重、撕裂 |
| 漫长寻找 | 冷青灰 6500K | 低 | 中高 | 阴天漫射、荧光灯 | 孤独、消耗 |
| 希望出现 | 暖白回归 5000K | 渐升 | 中 | 自然侧光 | 试探、微光 |
| 重逢高潮 | 暖白高光 4000K | 中 | 中低 | 逆光、光晕 | 释然、泪光 |
| 现实落点 | 原始质感 | 不修饰 | 不修饰 | 手持粗粝、真实光 | 真实、沉重 |

**原则**：调色变化必须随叙事推进，不能无动机跳色。同一阶段内保持一致。跨年蒙太奇可以同构图内只换色温。

## 节奏法则

### 片长与镜头数

| 总时长 | 镜头数 | 单镜均长 | 特点 |
|---|---|---|---|
| 60s | 12–16 | 4–5s | 紧凑版情感短片 |
| 120s | 22–30 | 4–5s | 标准情感短片 |
| 180s | 32–42 | 4–5s | 完整情感叙事 |
| 240s | 42–55 | 4–5s | 长片，需要更多蒙太奇段 |

### 节奏控制

- **每 15–20 秒给一个信息变化**：不一定是动作，可以是光线、音乐进入、旁白转折、道具状态变化；
- **允许长停留**：叙事者沉默、凝视、行走的镜头可停 5–8 秒；
- **高潮段放慢**：情绪爆发时镜头反而更长，不要用快剪堆情绪；
- **蒙太奇段加速**：跨年段落可用 1.5–2.5 秒短镜连切；
- **重要信息后留黑场**：关键台词或画面后留 0.5–1.5 秒黑场。

### 镜头排列节奏示例（180s 标准片）

```
0–15s   建立场面和人物（背影跟随 + 环境空镜）
15–30s  幸福基线（暖色 + 旁白进入 + 手部/道具）
30–45s  失去/转折（色温骤变 + 侧脸 + 环境空镜）
45–75s  寻找/消耗（冷色 + 背影跟拍 + 年份蒙太奇）
75–90s  希望微光（色温暖回 + 侧脸 + 远景）
90–105s 重逢/高潮（暖白高光 + 情绪特写 ×1 + 拥抱）
105–120s 回味（空镜 + 旁白收束）
120–180s 真实素材混剪 + 公益口号 + 黑底白字
```

## 旁白体系

### 旁白是叙事主体

在情感叙事风格中，旁白不是补充，是主体。画面是旁白的视觉化。

### 旁白格式

- **括号体内心独白**为主要格式：（我的时间好像停在了那一年）
- 不用"他/她"叙述，用"我"——即使镜头是第三人称；
- 短句为主，单句不超过 15 字；
- 关键句前后留 1–2 秒安静；
- 旁白总量控制在时长的 30–40% 以内。

### 旁白与画面的关系

| 旁白做什么 | 画面做什么 |
|---|---|
| 交代时间背景 | 展示年代环境空镜 |
| 说出内心判断 | 展示人物背影或侧脸 |
| 说出决心 | 展示行动（行走、推门、签字） |
| 说出代价 | 展示空房、合同、车站 |
| 说出希望 | 展示他人的团圆或远景暖光 |
| 沉默 | 留给画面和音乐 |

### 对白

- 对方朝镜头方向说话（不直视镜头，但面向镜头方向）；
- 短句优先（5–12 字），长句拆成多次开口；
- 方言增强真实感，字幕必须为标准书面语；
- 关键对白（"万一真是我女儿呢"）单独成镜，前后留白。

## 音乐体系

### 三层音乐策略

| 层 | 内容 | 进入时机 |
|---|---|---|
| 底层环境 | 风声、车流、雨、安静室内 | 全片底噪 |
| 情绪钢琴 | 单音/简单旋律 | 旁白进入后或情绪转折点 |
| 高潮弦乐 | 弦乐群或人声吟唱 | 重逢/高潮段，从情绪特写前进入 |

### 音乐使用法则

- 音乐不在开头立即进入，让环境声先建立真实感；
- 一次只用一层情绪音乐，不叠加；
- 高潮段音乐达到最响，然后在黑场前骤停；
- 真实素材段不用配乐，只保留现场声；
- 结尾口号段可用极轻的钢琴尾音。

## 真实素材混剪

情感叙事风格的关键差异：AI 生成段后面接真实或伪纪录素材，形成现实冲击。

### 混剪结构

```
AI 叙事段（精致、电影感）
  ↓
黑场 0.5–1s
  ↓
真实/伪纪录素材段（粗粝、手持、直接）
  ↓
黑底白字公益口号（静态、慢淡入）
```

### 真实素材要求

- 使用已授权素材或用 AI 模拟"真实感"（降低画质、加手持抖动、减少后期）；
- 内容为家属举牌、人群、标语、公益现场；
- 所有真实姓名、电话、照片必须虚构或已授权；
- 真实素材段不配乐，只保留现场环境声。

## 方言与对白

### 方言使用原则

- 叙事者对白和路人对话可使用西南方言（四川/重庆话）增强地域真实感；
- 旁白使用普通话；
- 字幕全部为标准书面语；
- 关键情感台词保留方言原味，字幕可标注（方言）。

### 常用方言台词模板

| 场景 | 普通话 | 方言版本 |
|---|---|---|
| 询问路人 | 大哥你见过这个小女孩吗？ | 大哥你见过这个小妹没有？ |
| 路人回应 | 太可怜了，孩子丢了 | 造孽哟，娃儿丢了呀 |
| 焦急自语 | 万一是我女儿呢 | 万一真是我女儿呢 |
| 售票对话 | 去哪里？ | 去哪里？ |
| 不知去向 | 我不知道去哪 | 我也不晓得哪里人多 |

方言不是必须，但能显著提升真实感和地域辨识度。用户未指定时标注为可选。

## 真实事件“善意接力”变体

适用于外卖备注、陌生人帮助、商家赠物、网友接力、公益扩散等短周期真实事件。不要硬套“长期执念与重逢”的多年时间线。

**推荐节拍（90–150s）**：日常基线 → 触发信息 → 阅读停顿 → 小额但具体的行动 → 受助者现实处境 → 简短回应 → 社会扩散 → 善意转赠 → 伪纪录现实落点 → 黑底短句。

**镜头分配**：
- 背影跟随 25–35%，集中在“做出行动、继续工作、向他人递出”三段；
- 手部特写 18–25%，用于手机、纸币、餐盒、订单等可见行动；
- 侧脸与越肩 15–20%，用于阅读、回应、意识到扩散；
- 环境空镜 10–15%，用于店铺、病房、街道换气；
- 情绪特写只在“收到回应”后使用一次，≤2s。

**叙事原则**：
1. 核心不是“一个好人”，而是“善意如何从一人传到多人”；
2. 金额、物品和订单数量必须来自用户材料，未核实信息不新增；
3. 医疗困境只给环境、陪护姿态和已知背景，不消费患儿正脸；
4. 真实姓名、订单、地址、手机号和平台界面默认做匿名化后期资产；
5. 结尾伪纪录段用现场声替代配乐，必须拆成单一动作镜头，禁止一个长镜塞入多场景；
6. 括号体旁白宜从行动者第一人称出发，例如“（我能做的不多）”，画面则展示手部行动，不复述旁白。

## 完整镜头清单

以下为情感叙事风格的标准镜头池。每个项目从中选用，不必全部使用：

| 编号 | 镜头类型 | 占比 | 典型用途 |
|---|---|---|---|
| EN-01 | 远景背影跟随 | 10% | 开场建立、行走蒙太奇 |
| EN-02 | 中景背影跟随 | 20% | 日常跟随，主力镜头 |
| EN-03 | 近景背影 | 5% | 紧迫、亲密 |
| EN-04 | 侧脸 45°旁观 | 15% | 情绪积累、反应 |
| EN-05 | 侧脸 90°正剖面 | 5% | 强烈情绪、对峙 |
| EN-06 | 手部特写 | 12% | 情感载体、道具互动 |
| EN-07 | 环境空镜 | 12% | 换气、时间暗示 |
| EN-08 | 情绪特写 | 3% | 高潮（≤3 次，≤2s/次） |
| EN-09 | 越肩旁观 | 8% | 对话 |
| EN-10 | 跨年蒙太奇 | 7% | 时间压缩 |
| EN-11 | POV 片段 | 3% | 沉浸关键瞬间（可选） |
| EN-12 | 低角度仰拍 | 2% | 压迫感（被拒绝、被训斥时） |
| EN-13 | 高角度俯拍 | 2% | 渺小感（空房、车站独自坐着） |
