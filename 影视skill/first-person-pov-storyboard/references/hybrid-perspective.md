本 Skill 默认采用情感叙事风格（第三人称为主）。本文件定义何时可以穿插其他视角、如何安全混合。

## 视角模式选择

在拆镜前先确定本片的视角模式：

| 模式 | 说明 | 适用 | 默认 |
|---|---|---|---|
| **情感叙事** | 第三人称为主（背影跟拍+侧脸+手部），穿插 POV 片段 | 2–4 分钟情感短片 | ✅ 默认 |
| **混合叙事** | 第三人称与 POV 交替使用，比例接近 | 长片、多角色故事 | |
| **POV 主导+短切出** | 80%+ POV，在情绪高峰短切 1–3s 第三人称 | 沉浸式短片 | |
| **纯 POV** | 全程叙事者眼睛位置，禁止任何外部旁观镜头 | 产品体验、恐怖 | `--pov` |

选择依据：用户未指定时默认情感叙事；用户明确要求"第一人称"时用纯 POV（`--pov`）。

## 情感叙事中的 POV 穿插

情感叙事以第三人称为主，但在以下时刻可以穿插 1–2 个 POV 片段：

| 何时穿插 POV | 目的 | 示例 |
|---|---|---|
| 拿起关键道具 | 让观众"变成"主角体验那一刻 | 叙事者拿起订单备注手机 |
| 推开关键门 | 沉浸式进入新空间 | 推开母亲家的门 |
| 看到重要信息 | 让观众和主角同时看到 | 读信、看屏幕 |

**限制**：POV 片段全片不超过 10%，每次不超过 3 秒，穿插后必须回到第三人称。

## 情感叙事中的正面镜头

虽然默认不拍叙事者正脸，但以下情况可以例外：

| 何时拍正面 | 目的 | 限制 |
|---|---|---|
| 情绪特写 | 高潮爆发——只拍局部（眼角/嘴角/泪痕） | ≤2s，≤3 次 |
| 对镜说话 | 对方角色直视镜头方向（不是直视叙事者，是直视镜头=直视叙事者方向） | 只用于对白镜头 |
| 镜子/倒影 | 短暂信息——叙事者在镜中看到自己 | ≤2s，不取代主视角 |

**禁止**：叙事者直视镜头（那打破"旁观者"的观察距离），除非是有意的对镜告白。

## 混合规则

### 情感叙事模式的混合规则

1. **背影跟拍占 30%+**（或至少 25%）——这是主力主视角。
2. **情绪特写全片不超过 3 次**，每次 ≤2 秒。
3. **POV 片段全片不超过 10%**，穿插后必须回切第三人称。
4. **色温必须随叙事推进变化**，不能全片一个色调。
5. **旁白与画面错位**——旁白给内心，画面给动作，不重复。
6. **AI 段后接真实素材**——形成社会落点。
7. **不在同一段落内频繁切换视角**——一个节拍内保持同一视角。

### 纯 POV 模式的混合规则

1. **每次切出不超过 3 秒**，否则观众失去沉浸感。
2. **切出总时长不超过全片 20%**。
3. **切出后必须回切 POV**，不连续停留在第三人称超过两镜。
4. **用户要求纯 POV 时禁止使用任何切出镜头**。

## 混合时的提示词写法

### 情感叙事镜头

使用 `perspective` 字段标记视角类型：

```json
{"perspective": "中景背影跟随", "pov_evidence": []}
```

提示词中直接写第三人称视角描述：
```text
从人物身后约两米处跟随拍摄，可见[服装特征]和[随身物]，前方是[环境]，[光线]，[情绪]，[画幅]。引用资产：[编号]。
```

### POV 片段穿插

```json
{"perspective": "POV", "pov_evidence": ["身体:右手持手机", "视线:看屏幕"]}
```

提示词恢复第一人称写法：
```text
第一人称眼睛高度，[身体证据]，[动作]，[视线目标]，[画幅]。引用资产：[编号]。
```

## 混合时的负面词调整

### 情感叙事模式（默认）

- 不禁背影、侧脸、越肩（这些是主力镜头）
- 禁航拍、监控视角、叙事者直视镜头
- 禁稳定器平滑感、环形绕拍

### 纯 POV 模式

- 禁第三人称、叙事者全身、背影、航拍、越肩
- 切出镜头的 `pov_evidence` 可改为 `"视角:背影跟随"` 等

## 短视频平台高赞模式

基于对头部 AI 叙事创作者（如"旧梦留声机"）的观察：

### 封面策略
- **双格封面**：左格情绪/氛围，右格关键道具或人物，底部叠加两字标题加书名号。
- **标题选词**：抽象情感词（《守护》《归栖》《微光》《本真》《种子》）。
- **统一封面风格**：全账号视觉一致。

### 节奏策略
- **慢节奏长片可行**：2–4 分钟在短视频平台成立，前提是情绪密度足够。
- **每 15–20 秒给一个信息变化**。
- **允许长时间静止**：沉默、凝视、行走的镜头可停留 5–8 秒。

### 旁白策略
- **括号体内心独白**：（我的时间好像停在了那一年）。
- **旁白与画面错位**：画面给动作，旁白给内心。
- **关键台词留白**：重要旁白前后留 1–2 秒安静。

### 视觉母题
- **贯穿道具重复出现**：同一物品在不同时间反复出现。
- **手部作为情感载体**：手部特写本身就是情绪表达。

### 色彩策略
- **暖色回忆 vs 冷色现实**。
- **低饱和为主**。
- **重要段落用单一主色**。
