| 用户诉求关键词 | 范式 |

| 寻找、等待、坚持、多年、重逢、公益、外卖备注、订单 | A |
| 意外、失去、一天之内、崩塌、事故 | B |
| 线索、真相、调查、密室、失踪 | C |
| 学会、第一次、训练、突破、比赛 | D |
| 开箱、试用、测评、上手、种草 | E |
| 旅行、citywalk、通勤、探店、日常 | F |

| 告白、道别、思念、家书、纪念 | H |

题材混合时以主情绪为准，借用其他范式的局部节拍。

### 真实事件“善意接力”变体

外卖备注、商家赠物、陌生人帮助、网友刷单和公益扩散虽然常出现“订单/公益”关键词，但不应机械套用多年寻找结构。此类题材按短周期闭环组织：

`日常基线 → 触发备注 → 具体行动 → 受助者处境 → 简短回应 → 网友接力 → 转赠他人 → 伪纪录现实段 → 黑底短句`

关键设计：以订单备注、现金、餐盒或回信作为三段式视觉锚点；用手部特写证明行动真实发生，用背影跟随承接行动者继续工作和走向他人；社会扩散段用同构图订单连切，现实段拆为骑手与环卫工等独立单动作镜头。建议片长 90–150 秒、22–35 镜。

## 范式 A：长期执念与重逢

**内核**：一个人为一个目标消耗整段人生，观众衡量的是代价而非事件。

这是博主"旧梦留声机"的主力范式，也是情感叙事风格最典型的应用场景。

### 节拍结构（120–180s 标准版）

```
1. 钩子开场（5–8s）   ：直接给命运转折点——手部持核心道具 + 旁白第一句
2. 幸福基线（10–15s）  ：暖色回忆，建立"曾经有多好"
3. 失去瞬间（5–8s）   ：色温骤变，不需要解释原因，只给反应
4. 决心启动（8–12s）   ：背影跟拍开始，旁白说出决心
5. 反复尝试蒙太奇（15–25s）：同构图跨年，道具磨损，服装变化
6. 代价展示（8–12s）   ：空房、合同、车站——具体可见的代价
7. 至暗时刻（5–8s）   ：高角度俯拍或低角度，环境压迫
8. 微光出现（8–12s）   ：色温暖回，侧脸可见希望
9. 高潮重逢（10–15s）  ：暖白高光 + 情绪特写×1 + 拥抱或对视
10. 回味余韵（8–12s）  ：空镜 + 旁白收束
11. 现实落点（10–20s） ：真实/伪纪录素材 + 黑底白字
```

### 关键设计

- **贯穿锚点**：必须有一件道具（一张照片、一件衣服、一个玩具、一张订单备注）反复出现，承担时间转场。锚点从崭新到磨损到最终状态，是全片的时间证据。
- **幸福基线要够暖**：暖黄 3200K，柔光，胶片颗粒。如果基线不够暖，后续冷调没有落差。
- **代价必须具体可见**：卖房给空房镜头，辞职给收起的工牌，被骗给空账户——不能只靠哭。
- **色温即情绪曲线**：幸福→暖黄；失去→中性骤冷；寻找→冷青灰 6500K；希望→暖白回归 5000K；重逢→暖白高光 4000K。
- **背影跟拍占 30%+**：在"决心启动"和"反复尝试"段，背影跟拍是主视角。
- **情绪特写只用 1–2 次**：留到最后的高潮段，不提前透支。
- **真实素材混剪结尾**：AI 叙事段结束后接真实或伪纪录素材，形成社会落点。

### 封面与标题

- 标题选词：抽象情感词（守护、归栖、微光、本真、种子、余光、归途、暮色）。
- 封面左格：命运转折点的情绪画面（冷色背影或暖色回忆）。
- 封面右格：贯穿道具特写（照片、玩具、订单备注）。

### 旁白结构

```
开场钩子   ：（那一年，我[失去/发现/接到]了[什么]）—— 给命运转折点
幸福基线   ：（那时候[谁]还在）—— 给温暖
决心启动   ：（我要找到[目标]）—— 给决心
代价展示   ：（后来[什么]也没了）—— 给代价
微光出现   ：（直到[某天]）—— 给转折
高潮收束   ：（[目标]……终于[实现]）—— 给完成
回味       ：（如果[什么]没有发生）—— 给假设性回望
```

### 易错

- 只堆情绪不给代价 → 观众感受不到重量；
- 锚点中断 → 时间线断裂；
- 重逢过度煽情 → 情绪溢出，应该从失控回到克制；
- 旁白太多 → 观众被信息淹没，总量控制在 30–40%；
- 色温无变化 → 全片一个色调，情绪没有起伏。

## 范式 B：一日崩塌

**内核**：24 小时内平静生活被打破。

**节拍**：日常仪式 → 微小异常 → 确认坏消息 → 徒劳补救 → 关系冲突 → 彻底失控 → 灰烬中的选择。

**关键设计**：用重复的日常动作（刷牙、通勤、开门）建立"正常"，再让同一动作在结尾变形；时间标记用光线而非字幕。

## 范式 C：悬疑探索

**内核**：观众与叙事者同步获取信息。

**节拍**：接到线索 → 进入空间 → 发现异常 → 建立假设 → 假设被推翻 → 危险逼近 → 真相揭示。

**关键设计**：每镜只给一条信息；用遮挡与画外声制造未知；手电、手机光营造有限视野。

## 范式 D：技能与成长

**内核**：从笨拙到熟练的手部叙事。

**节拍**：动机 → 首次失败 → 拆解要领 → 重复练习 → 瓶颈 → 微小突破 → 检验时刻。

**关键设计**：全部依赖手部特写与视线；用同一动作的三次质量差异表现进步；练习段用节奏剪辑压缩时间。

## 范式 E：产品体验与开箱

**内核**：让观众以为是自己在用。

**节拍**：需求痛点 → 拿到手 → 触感与细节 → 首次使用 → 关键功能验证 → 对比或场景延展 → 结论。

**关键设计**：手与产品比例必须真实；细节镜头交代材质与做工；使用镜头必须展示真实反馈。

## 范式 F：旅程与城市漫游

**内核**：空间移动本身就是叙事。

**节拍**：出发准备 → 进入路径 → 第一个驻足 → 与人相遇 → 意外插曲 → 抵达 → 回望。

**关键设计**：行走镜头必须有眼高起伏和手臂摆动；用声音层次区分街区；驻足镜头要有明确注视目标。

## 范式 G：恐怖与生存

**内核**：可见范围受限带来的压迫。

**节拍**：安全状态 → 首个异常信号 → 探查 → 遭遇 → 逃离 → 短暂喘息 → 二次遭遇 → 结局。

**关键设计**：限制光源与视野；把威胁放在画外用声音定位；呼吸声是主乐器。

## 范式 H：情感告白与回忆

**内核**：静态空间中的内心运动。

**节拍**：触发物 → 回忆闪回 → 现实落差 → 未说出口的话 → 释然或遗憾。

**关键设计**：回忆段用眨眼、失焦、光线变化进入；回忆中的对方要直视镜头；现实段保持克制与静止。

## 时长与镜头数配比

| 总时长 | 建议镜头数 | 单镜均长 | 节拍数 |
|---|---|---|---|
| 15s | 4–6 | 2.5–4s | 3 |
| 30s | 7–11 | 3–4s | 4–5 |
| 60s | 14–20 | 3–5s | 5–7 |
| 90s | 20–28 | 3–5s | 6–8 |
| 120s | 22–30 | 4–5s | 8–10 |
| 150s | 32–46 | 3–5s | 8–11 |
| 180s | 32–42 | 4–5s | 10–11 |
| 240s | 42–55 | 4–5s | 11–13 |

高潮段可放慢至 5–6 秒，蒙太奇段可压到 1.5–2 秒。排镜后必须实数核对合计时长。

## 平台适配

| 平台形态 | 画幅 | 前 3 秒策略 | 注意 |
|---|---|---|---|
| 竖屏短视频 | 9:16 | 首镜即给冲突或强手部动作 | 主体居中偏上，避开底部字幕区与顶部信息区 |
| 横屏叙事 | 16:9 | 可用 5 秒建立氛围 | 利用画面两侧安排环境信息 |
| 方形信息流 | 1:1 | 中心构图，快速给结论 | 避免依赖边缘细节 |
| 沉浸式大屏 | 21:9 | 强调空间纵深 | 加强前景遮挡以维持第一人称 |

竖屏情感叙事注意：背影跟拍时人物占画面中下部，留出上方环境空间制造纵深。
