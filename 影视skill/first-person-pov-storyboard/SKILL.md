# AI 影像分镜与资产设计

只交付真正可生成、可剪辑的方案。每个镜头都有明确的视角归属、注视对象和动作因果。

## 默认风格

用户未指定时默认采用**情感叙事风格**：以第三人称旁观为主视角，用背影、侧脸、手部和环境细节讲述被时间改变的故事。详见 [references/emotional-narrative.md](references/emotional-narrative.md)。

如果用户明确要求第一人称 POV，切换为纯 POV 模式，详见下文"POV 成立门槛"和 [references/shot-grammar.md](references/shot-grammar.md)。

## 工作流

1. 完整读取用户提供的故事、文案、视频、网页、图片或既有分镜。
2. 提炼项目约束：主题、叙事者、受众、片长、画幅、年代、地点、风格、平台、生成工具、素材授权状态。
3. 确定风格模式：情感叙事（默认）/ 纯 POV / 混合视角。
4. 选叙事范式并定节拍（查 genre-playbooks.md）。
5. 建立视角规则与连续性圣经。
6. 先规划图片资产（含封面），再写镜头提示词；所有镜头引用统一资产编号。
7. 选镜头类型并写关键帧与动态提示词（查 emotional-narrative.md 或 shot-grammar.md）；用户要“视频提示词”或完整生产方案时，必须再读 production-video-prompts.md，按题材选择参数，不得只交付简略动态描述。
8. 设计封面与标题（查 cover-and-title.md）。
9. 补声音、字幕与剪辑方案（查 sound-and-edit.md）。
10. 跑机器校验，再做人工复检，修改产物本身。
11. 若为真实事件“善意接力”题材，按 `emotional-narrative.md` 的专用变体处理：不硬套多年寻找结构，隐私字段全部拆为匿名化 T 类资产，现实段拆成单动作伪纪录镜头。

如果用户只要其中一部分，只输出所需部分，但仍在内部完成必要的视角与连续性检查。

## 输入不足时的默认值

只有歧义会导致方向性返工时才提问；否则标注假设并继续。

- 未给片长：按故事复杂度设计精简版；标准情感叙事默认 120–180s，单事件“善意接力”类默认 90–150s。
- 未给单镜时长：背影跟拍和侧脸旁观 4–5s，蒙太奇 1.5–2.5s，情绪特写 ≤2s。
- 未给画幅：短视频采用 9:16。
- 未给视觉风格：采用情感叙事风格（克制现实主义、低饱和、电影质感）。
- 未给生成模型：使用模型中立、自然语言可迁移的提示词，不编造参数。
- 未给真实人物或文本授权：使用虚构身份、虚构号码与占位文字，并注明后期替换。
- 未给封面风格：采用双格+两字标题格式。

## 情感叙事风格核心

### 镜头语言

默认以第三人称旁观为主视角，镜头语言详见 emotional-narrative.md。核心镜头类型：

| 类型 | 占比 | 用途 |
|---|---|---|
| 背影跟随 | 30–40% | 主力镜头，建立空间和时间 |
| 侧脸旁观 | 15–20% | 情绪积累 |
| 手部特写 | 10–15% | 情感载体 |
| 环境空镜 | 10–15% | 换气、时间暗示 |
| 情绪特写 | ≤3次 | 高潮（每次 ≤2s） |
| 越肩旁观 | 5–10% | 对话 |
| 跨年蒙太奇 | 5–10% | 时间压缩 |
| POV 片段 | 0–10% | 可选，沉浸关键瞬间 |

### 影调体系

色彩即情绪。每个叙事阶段必须有明确的色温、饱和度和对比度目标，详见 emotional-narrative.md 影调体系表。调色变化必须随叙事推进。

### 旁白

旁白是叙事主体，画面是旁白的视觉化。使用括号体内心独白（"我"视角），短句，总量控制在时长的 30–40%。旁白与画面错位——旁白给内心，画面给动作。

### 真实素材混剪

AI 叙事段结束后接真实或伪纪录素材，形成现实冲击。AI 段精致电影感，真实段粗粝手持感，不做风格统一。

## POV 成立门槛（纯 POV 模式时适用）

用户明确要求纯 POV 时，切换到以下规则：

### 1. 明确镜头主人

为叙事者固定：年龄阶段、身高区间、惯用手、服装袖口、手部特征、随身物；当下目标、情绪和身体状态；眼睛高度、移动方式和动作能力；不同年代或阶段的可见变化。

### 2. 每镜至少提供两类 POV 证据

- **身体证据**：双手、前臂、膝盖、脚步、呼吸起伏、影子、局部倒影；
- **视线证据**：从手中物抬眼看人、低头、回头、眨眼、被遮挡后重新看见；
- **互动证据**：对方直视镜头、向镜头递物、扶住镜头主人、从镜头主人手里接物；
- **动作证据**：推门、拿起、放下、奔跑、坐下、拥抱造成符合身体的镜头位移；
- **锚点证据**：同一件手持物或身体标识稳定处于前景。

### 3. 禁止偷切第三人称（纯 POV 模式下）

- 从外部拍到叙事者完整身体或背影；
- 无来源的航拍、上帝视角、越肩反打、旁观式双人全景；
- 镜头穿墙、脱离人体飞行或做不符合头部运动的轨迹。

### 4. 让运镜服从身体

使用可感知的人体动作描述，而非空泛的摄影术语。

## 连续性圣经

在拆镜前锁定以下对象并分配编号：

- `N`：叙事者身体与阶段；
- `C`：可见角色；
- `P`：剧情道具与视觉母题；
- `L`：地点与年代版本；
- `T`：需要后期制作的文字、屏幕或图形资产；
- `CV`：封面资产（左格、右格、标题文字、合成图）；
- `S`：声音母题。

为每项记录"不变量"和"允许变化"。跨年份时让同一前景锚点承担时间转场。

## 图片资产规划

先输出资产清单，再输出分镜。完整格式与提示词公式见 output-spec.md。

至少判断是否需要：

1. 叙事者全身/侧脸/背影参考（情感叙事模式需要更多角度）；
2. 主要角色身份参考与年龄版本；
3. 贯穿道具的干净版、使用版、磨损版；
4. 场景空镜与年代版本；
5. 封面左格、右格与标题文字资产；
6. 可读文字、手机界面、证件、海报等独立后期资产；
7. 色彩、光线与材质参考板。

## 分镜拆解

### 先拆叙事节拍

每个节拍只承担一个主要功能：建立、触发、行动、阻碍、代价、发现、转折、高潮、余韵。每个镜头必须能回答：

- 叙事者此刻想做什么？
- 观众先看见什么，随后看见什么？
- 哪个视觉信息推动下一镜？
- 为什么用这个视角？

### 再写镜头

每镜按"刺激 → 注视 → 动作 → 反馈 → 出镜点"设计。一镜只保留一个主要动作和一个主要情绪变化。复杂交互拆成多个镜头。

## 提示词写法

### 关键帧提示词

按以下顺序写成自然段：

`视角类型与画面 + 人物可见部分 + 正在进行的动作 + 场景/年代 + 前中后景构图 + 光线色彩 + 材质和情绪 + 画幅`

必须明确哪些物体清晰、哪些物体虚化。

### 图生视频动态提示词

只描述这一镜中可观察、可完成的变化：

`起始状态 → 人物/镜头运动 → 手部或身体动作 → 环境反馈 → 对焦/遮挡变化 → 结束状态`

### 图生视频生产级提示词

用户要求视频提示词时，不能只输出“起始状态→动作→结束状态”的短句。每镜必须按 `production-video-prompts.md` 输出：首句规格与时长、参考资产锚定、场景、运镜、按秒动作、尾帧、音效、影像调性、表演要求、对白/旁白、反向锚定、后期与 QC。字段随题材调整但不得遗漏必要约束；动作时间轴必须与本镜时长一致。

### 负面词

按视角模式调整：

- 情感叙事模式：不禁背影、侧脸、越肩（这些是主力镜头），但禁航拍、监控视角、叙事者直视镜头；
- 纯 POV 模式：禁第三人称、叙事者全身、背影、航拍、越肩；
- 共通禁止：多手多指、人物换脸、服装突变、道具版式变化、文字乱码、品牌水印、塑料皮肤、真实电话、真实证件号、未授权真人肖像。

## 机器校验

镜头较多或需要交付前自检时，把分镜整理成 JSON 后运行：

```bash
python3 scripts/check_storyboard.py <分镜.json>
python3 scripts/check_storyboard.py <分镜.json> --strict   # warning 也算失败
```

字段结构直接复制 `assets/storyboard-template.json`。通过 `perspective` 字段标记每个镜头的视角类型（如 `背影跟随`、`侧脸旁观`、`POV`），校验器会自动调整检查规则。

生产级视频提示词 Markdown 另运行：

```bash
python3 scripts/check_video_prompts.py <视频提示词.md>
```

它检查镜头编号、完整字段、首帧锚定、动作时间轴、单镜头、9:16、无生成字幕、反向锚定与 QC。

## 输出要求

完整任务必须按 output-spec.md 的顺序交付：项目设定、视角与连续性圣经、资产包（含封面）、节拍、逐镜执行表、逐镜提示词卡、封面与标题设计、全局风格锁、全局负面词、声音剪辑、QA。

提示词必须可直接复制，方括号仅用于用户尚未提供且不能合理推断的字段。

## 质量门禁

交付前逐项检查：

- 风格模式是否已确定且全片一致；
- 背影跟拍是否占全片 30% 以上（情感叙事模式）；
- 情绪特写是否 ≤3 次且每次 ≤2s；
- 色温是否随叙事推进变化；
- 旁白是否使用括号体内心独白且与画面错位；
- AI 段后是否有真实素材或伪纪录段形成现实落点；
- 封面是否为双格+两字标题格式；
- 人物、服装、道具是否跨镜一致；
- 相邻镜头的动作、视线、光线和声音是否可接；
- 每镜是否只有一个主要动作与一个主要情绪变化；
- 动态提示词是否描述了明确起止状态；
- 是否存在未授权肖像、个人信息、品牌或真实敏感材料；
- 总时长、镜头数和用户要求是否实数核对。

任何一项不合格，修改镜头或提示词本身，不要只在备注里提醒。
