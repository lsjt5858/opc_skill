# 剧本解析与视觉圣经

## Script Parser

把故事转换为可制作结构，而不是只做摘要。

### 提取内容

- 人物：身份、关系、欲望、阻力、秘密、变化弧、首次/末次出现。
- 场景：地点、内外景、时间、天气、剧情功能、空间动作。
- 道具：持有者、用途、首次出现、状态变化、伏笔与回收。
- 时间线：故事时间、闪回/插叙、昼夜、场景顺序、时间跨度。
- 剧情节拍：触发、升级、转折、发现、选择、高潮、余韵。
- 情绪节点：人物起始情绪、刺激、外显行为、压抑程度和转变。
- 关键时刻：不可替代、改变理解或决定结局的瞬间。

### 剧本解析规则

1. 为实体分配稳定 ID：`CHAR-01`、`SCENE-01`、`OBJ-01`、`BEAT-01`。
2. 区分“地点”和“场景”：同一老屋的白天与暴雨夜可共用 Scene Bible，但属于不同场次状态。
3. 区分“普通物件”和“叙事道具”：有伏笔、状态变化、近景或情感承载的物件进入 Object Bible。
4. 记录显性信息与推断信息；不要把推断伪装成剧本事实。
5. 梗概过短时，优先补足因果链，而不是堆画面。

## Visual Bible Builder

Visual Bible 是全片共享规则，不是几个风格形容词。

### 必备字段

- 世界：年代、国家、地域、社会环境、季节、天气、主要时间段。
- 类型：剧情、悬疑、爱情、现实主义、古风、赛博朋克、日漫、纪录片等及混合比例。
- 摄影：等效焦段倾向、景深、机位高度、主观/客观视角、稳定/手持、运动节制。
- 构图：对称/失衡、留白、遮挡、框中框、人物空间关系。
- 色彩：主色、辅助色、点缀色、肤色策略、饱和度、对比度、颜色叙事变化。
- 光线：自然/人工、方向、软硬、色温、昼夜规则、关键场景例外。
- 材质：木、布、皮革、金属、玻璃、墙面等的时代感和触感。
- 画幅：9:16、16:9、2.39:1 等及安全构图。
- 后期：胶片/数字电影/新闻摄影/纪录片，颗粒、锐度、黑位、高光和禁用效果。

### 视觉规则层级

1. **全片不变量**：真实度、时代、画幅、基础摄影与后期。
2. **章节变量**：随剧情阶段变化的色温、对比、镜头稳定性。
3. **场景变量**：地点和时段特有光线。
4. **镜头变量**：为叙事目的做的单次例外。

Visual Bible 应包含 `do` 与 `avoid`，例如现实主义可规定“保留生活杂乱和皮肤纹理”，并禁止“奢华广告布光、过度磨皮、无动机霓虹”。

## Bible Forge

### Character Bible

每个主要角色记录：

- 身份：姓名、叙事功能、年龄、职业、地域/生活背景。
- 身体：身高、体型、肤色、脸型、眼睛、鼻唇、发型和可识别特征。
- 服装：基础衣橱、剧情阶段服装、材质、颜色、旧化、配饰。
- 行为签名：站姿、步态、惯用手、动作习惯、说话节奏、口音、停顿、视线和表情方式。
- 心理：核心欲望、恐惧、防御方式、关系变化、每阶段心理状态。
- 一致性锚点：3–7 个画面中必须重复出现的特征。
- 可变项：服装、伤痕、疲态、情绪等随时间线变化的内容。

人物不能只靠“年龄+衣服+发型”保持一致。用微行为呈现内心，例如含胸、握手机、摸口袋、回避对视、说话前停顿。

### Scene Bible

每个复用地点记录：

- 地点身份、年代、地域、用途、居住/使用者。
- 空间尺寸、结构、入口、窗户、通道、固定机位和方位图。
- 墙面、地面、门窗、家具、窗帘、陈设及磨损。
- 主色、材质、气味/声场提示、生活痕迹。
- 固定光源、自然光方向、昼夜/天气状态。
- 必须保留的地标和禁止随机变化的元素。
- 剧情阶段状态：整洁、凌乱、损坏、空置等。

### Object Bible

叙事道具记录：

- 唯一 ID、名称、所有者、剧情功能。
- 年代、品牌风格；没有授权时避免真实商标。
- 类型、尺寸、比例、材质、颜色、重量感。
- 按钮、屏幕、镜头、接口等结构。
- 磨损位置、划痕、裂纹、污渍和维修痕迹。
- 初始状态、每次变化、最后状态。
- 与手部和环境的比例参照。
- 正面、背面、侧面、细节和在场使用视角。

“旧手机”必须锁定为同一台手机：同一外壳颜色、裂纹走向、按键布局、磨损边缘和屏幕状态。

## Bible 更新规则

- 新信息只更新对应实体；随后检查依赖它的提示词。
- 用户说“更沧桑”时，先判断是外观、行为、服装还是光线变化，不要全部同时夸张。
- 角色换装应新增 `look_id`，不覆盖基础身份锚点。
- 场景状态变化应新增 `scene_state_id`。
- 道具损坏或内容变化应新增 `object_state_id`。
