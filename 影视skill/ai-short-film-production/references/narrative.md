# 叙事引擎

## Asset Priority

资产优先级决定投入多少设定、多少视角和多少提示词。

### Priority A：核心资产

判断标准：反复出现、承担伏笔/回收、决定辨识度、参与高潮、跨多个镜头保持一致。

产出要求：完整 Bible、标准视图、细节视图、状态变化、使用场景、一致性负面约束。

### Priority B：重要资产

判断标准：推动一场戏、帮助识别人物/地点、出现多次但不承担核心转折。

产出要求：基础 Bible、主视图、必要状态和一致性锚点。

### Priority C：支持资产

判断标准：氛围、生活质感、单次使用且可替换。

产出要求：合并进场景或镜头提示词，不单独消耗大量篇幅。

优先级评价维度：出现频率、叙事功能、情感承载、连续性风险、画面辨识度、复用次数。不要只按出现时长；一秒钟的父亲握手机可能比十秒钟的走廊更重要。

## Story Importance

对剧情节拍和镜头评级：

- ★★★★★ 核心伏笔/揭示/选择/高潮：必须精准设计图像信息、表演和镜头；通常需要备选构图。
- ★★★★ 推动剧情：清晰展示动作、关系或新信息。
- ★★★ 氛围与人物状态：建立环境、节奏或心理。
- ★★ 补充信息：可与相邻镜头合并。
- ★ 过渡：尽量节省资产，避免喧宾夺主。

记录评级理由和该画面必须让观众获得的内容。五星不等于大场面；情感核心的微动作可以是五星。

## Emotion Library

情绪用“内部状态 + 抑制程度 + 可见行为”描述：

| Level | 状态 | 表演方向 |
|---|---|---|
| 1 | 平静/日常 | 呼吸均匀，肌肉放松，动作完整 |
| 2 | 克制/轻微波动 | 停顿变多，视线短暂回避，手部小动作 |
| 3 | 压抑/明显负荷 | 肩颈紧张，呼吸浅，句子中断，动作迟疑 |
| 4 | 崩溃前/濒临失控 | 下颌发紧，眼眶变化，手失去稳定，努力维持表面 |
| 5 | 爆发/释放 | 身体防御解除或骤然收紧，声音与动作出现不可逆变化 |

使用原则：

- 不把情绪等级当“夸张等级”；不同人物有不同表达方式。
- 同一节点可有表层情绪和底层情绪，例如“表层冷淡 Level 2，底层恐惧 Level 4”。
- 给出眼神、嘴角、呼吸、肩膀、手、站姿和动作节奏中的 2–4 个可见证据。
- 建立全剧情绪曲线，避免每个镜头都处于高位。

## Shot Library

### 景别

- ECU：极特写；眼睛、屏幕、裂纹、手指等不可替代细节。
- CU：特写；细微表演和情感转换。
- MCU：中近景；表情与手部动作兼顾。
- MS：中景；人物动作与关系。
- FS/WS：全身/全景；空间、孤独、距离和调度。
- EWS：大远景；世界尺度或人物渺小感。

### 视角与构图

- OTS：过肩，强调关系、对峙或信息差。
- POV：主观，限制观众所知并增强代入。
- Insert：插入镜头，道具或关键信息。
- Top Shot：俯拍，展示空间关系或压迫。
- Low/High Angle：仅在权力或心理表达有明确动机时使用。
- Frame within Frame：通过门窗、倒影、遮挡表达隔离或窥视。

### 运动与稳定性

- Locked：固定机位；克制、观察、无法逃离。
- Handheld：手持；不稳定、贴身、纪录感，避免无动机晃动。
- Push In：推进；认知或情绪逐渐聚焦。
- Pull Out：拉远；疏离、失去、揭示环境。
- Tracking：跟拍；持续行动和空间体验。
- Slow Dolly：缓慢移动；精确控制情绪靠近或远离。
- Pan/Tilt：揭示信息或跟随动作，不作装饰。

### 镜头选择顺序

先写：这个镜头让观众看见/感受什么；再选择景别、视角、运动、焦段和构图。不要先挑“酷镜头”。

## Shot Strategy

每个关键节拍至少记录：

```yaml
- beat_id: BEAT-01
  importance: 5
  audience_payload: 观众必须获得的信息或情绪
  subject: CHAR-01
  emotion:
    surface: 克制
    underlying: 恐惧
    level: 4
    visible_cues: []
  shot:
    size: CU
    angle: eye_level
    movement: slow_push_in
    lens_intent: 轻微压缩背景，隔离人物
    composition_intent: 大量负空间压迫人物
  continuity_state: []
```

## 分镜拆分

- 一个镜头尽量承载一个主要信息变化。
- 动作在镜头间按起势—过程—结果衔接，记录动作接点。
- 对话场景检查视线、轴线、反打背景和人物左右位置。
- 五星节点可增加建立、反应、插入和余韵镜头；低星过渡可合并。
- 每个镜头给稳定 `SHOT-001` ID，并引用实体与状态 ID。
- 默认避免把每句台词都切一镜，优先按情绪和信息变化切镜。
